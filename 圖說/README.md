## 固定版面（九年一致）

```
A1 橫式 841 × 594 mm
┌── 左 22%（180mm）──┬──── 中 52%（430mm）────┬── 右 26%（207mm）──┐
│ ① 基地硬條件與環境   │  主配置圖（含開挖範圍）    │ 標題帶            │
│ ② 英雄條件・課題對策 │  A-A' 剖立面             │ 申論題（30 分）    │
│ ③ 空間需求・量體     │  B-B' 剖立面             │ 官方圖說要求打勾   │
│ ④ 人車動線・防災管理 │  局部透視                │ 數值證據分級       │
│                    │                         │ 交卷前檢核         │
│                    │                         │ 法規檢核對照       │
│                    │                         │ 課題→對策→效益     │
│                    │                         │ 基地核對（疊合）   │
│                    │                         │ 量體計算式         │
└────────────────────┴─────────────────────────┴──────────────────┘
```

## 重跑

```bash
cd 圖說
python3 board_110.py                  # 110 為手寫腳本（校正版基準）
python3 board_112.py                  # 其餘八年走 board_builder
for y in 106 107 108 109 111 112 113 114; do python3 board_$y.py; done
for f in boards/*.svg; do rsvg-convert -w 2400 "$f" -o "${f%.svg}.png"; done
pdfunite boards/10*.pdf boards/11*.pdf boards/106-114_敷地計畫考場大圖_合訂.pdf
python3 gen_tables.py                 # 重新產生逐年數值表
```

## 檔案

| 檔案 | 用途 |
|------|------|
| `board_engine.py` | A1 版面骨架、SVG 原語、公尺→畫框擬合（`Fit`）、比例尺、指北針 |
| `board_builder.py` | 九年共用之左欄四格、剖立面、透視、右欄全部表格 |
| `board_1xx.py` | 各年基地幾何（公尺）、量體、平面專屬圖元、全部文字 |
| `gen_tables.py` | 由 spec 直接產生逐年數值表（單一事實來源） |

> ⚠️ 本組圖為**示範方案（非唯一正解）**。法規／數字請以全國法規資料庫為準；
> 各年數字之更正依據見 [22 專業審查修正彙編](../敷地計畫與都市設計/22-專業審查修正彙編.md)。
