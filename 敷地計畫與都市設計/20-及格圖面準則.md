# 20 及格圖面準則（能過 × 專業）

> 版本：v1.0｜2026-08-09
> 依據：某及格考生 **106–114 共九年**復原圖之實地分析
> 核心命題：**「能過」與「專業」是兩件事。** 能過是**有沒有**（二元），專業是**好不好**（程度）。
> **先把「能過」六項全部做到，再談專業。** 順序顛倒就是你 114 的失分模式（設計不差、圖說缺項）。

---

# PART A：「能過」的六道門檻

> 這六項是**二元判定**——做到得分，沒做到直接扣。九張及格圖，**六項全中**。

## A1. 圖說項目一項不缺 ★最高優先

題目要幾張就畫幾張，**名稱照抄題目用詞**。

| 年 | 題目要求 | 他畫了 |
|----|---------|-------|
| 112 | 配置圖／機能組織圖／剖立面≥2向／**透視≥2處** | 全數到齊 |
| 113 | 規劃構想／量體配置（含一樓平面、開挖範圍）／機能關係／剖立面≥1／**透視≥1** | 全數到齊 |
| 111 | 地面層配置／**剖面兩向**／**標準層平面**／房型計算表 | 全數到齊（含 A-A'、B-B' 兩向）|

> **執行動作**：開卷後把圖說清單抄在圖紙角落，**每完成一項打勾**。
> ⚠️ 你 114 缺「外部空間局部透視圖」，就是沒做這個動作。

## A2. 量體計算做出來、寫在圖上、打勾

```
建築面積 = 564＋960＋256 = 1,600 ㎡ ≤ 3,596×80% = 2,876.8 ㎡ … ok!
容積面積 = 512×2＋960×6＋1,450×2 = 10,708 ㎡ ≤ 3,596×400% = 14,384 ㎡ … ok!
```

> 「**… ok!**」＝自我檢核。九張圖有八張都有這個寫法（108 也是 `…OK!`）。

## A3. 題目點名的條件，逐項在圖上回應

題目寫進去的每一個特殊條件，圖上都要找得到對應：

| 條件類型 | 圖上要出現 |
|---------|-----------|
| 退縮規定（如西南側退縮 4M）| 配置圖畫出退縮線＋標註 |
| 既有樹木／老樹 | 畫出來並標「原地保留」 |
| 歷史遺構（水圳、廟宇）| 標示位置＋不開挖／再現手法 |
| 出入口分設（汽/機車）| 兩個箭頭分別標示 |
| 高架道路／噪音源 | 標緩衝或隔離手法 |
| 地下開挖 | 紅虛線框＋「開挖範圍」紅字 |

## A4. 剖面圖有足夠資訊密度

**三件事缺一不可**：
1. **頂部**標出剖到的每一段名稱與寬度
2. **右側**每一層標樓高數字
3. 關鍵淨高（如羽球場 6.1M）明確標出

> ⚠️ 你 114 的剖面偏小、樓高不清——這一項是**你最大的失分點之一**。

## A5. 版面填滿、無大片空白

三欄式版面（左分析／中配置＋剖面／右標題＋申論）**天然就會填滿**。

## A6. 申論有結構：段段小結、最後總結

> 你 114 已經做到這項，**保持住**。

# PART B：「專業」的八個質感

> 這八項是**程度判定**——做了會讓考官覺得「這人是真的在做設計」。

## B1. 標題＋副標一行串機能（30 秒，效果最大）

| 年 | 主標 | 副標 |
|----|------|------|
| 106 | 樂而忘齡・共齡共照 | 健康/交流/學習/無障礙 |
| 107 | 職人共創聚落 | 活力文創/多型態廣場 |
| 108 | 友善綠家園 | 交流/學習/樂活/共融 |
| 109 | 活力綠校園 | 永續、創新、學習！ |
| 112 | 都市教育方舟 | 公益開放/教育研修/環境永續/水圳再現 |
| 113 | 趣味生活宅 | 城市文化多樣性/快閃市集/社宅/社福 |
| 114 | 韌性樂活方舟 | 防災/停車場/運動休閒/永續節能設計/健康交誼 |

> **副標那一行等於一秒回答「題目要的我全部都答了」。**

## B2. 三行原則：文字全部標籤化

> **除申論區外，圖面上任何一處文字不超過 3 行。** 九年無一例外。

引線標註公式：**`名詞－效益`**，5–15 字。
- `退縮綠帶－隔噪音・廢氣`
- `街道家具－提供停留休息`
- `汽機車動線分流－提高安全性`

## B3. 樓層機能寫在量體方塊裡（不另畫平面）

```
RF 屋頂花園
6F 桌球館
5F 羽球場
4F 壁球場
3F 健身房・停車
2F 健康飲食・停車
1F 停車場・梯廳
```
> 同時回答了「垂直機能」與「空間組織」，省一張圖的時間。

## B4. 圖文編號對應

108 申論「火車站高架化」：文字 ①②③④⑤ 條列，旁邊示意圖上也標 ①②③④⑤。
> **文字負責講，圖負責指位置**——所以文字可以極短。

## B5. 剖面的紅色 [分類] 標註

```
[室內環境] 綠建材・低VOC材料
[日常節能] 遮陽・LED・高效設備
[基地保水] 透水鋪面・滲透側溝
[水資源]   雨水回收再利用
[廢棄物減量] 基地土方回填
[複層植栽] 增加生物多樣性
```
> 用中括號當分類標題，一組 5–6 個貼在剖面周圍——**永續設計最省時的表達法**。

## B6. 透視說故事（公式化）

> **`場所名稱＋在設計中的角色＋誰在這裡＋做什麼`**

113 原文：
> 「**大樹木平台**錨定了主廣場，為本設計的**精神中心**，逛街時可在此休憩、玩樂，並歡迎**學生、民眾**的到來。」

> 不是畫得美，是**文字把場所的意義講出來**。

## B7. 五色系統（只用五色）

| 色 | 用途 |
|----|------|
| 綠 | 植栽、綠地 |
| 藍 | 水體；**所有引線標註文字** |
| 黃／橘 | 開放空間、廣場、人行動線 |
| 紅 | 重點、開挖範圍、[分類標題] |
| 灰 | 周邊既有建物（襯底，不搶戲）|

## B8. 「└」符號做次階說明

```
1. 人本交通
 └ 人車分離、連續步行動線
2. 室內外無障礙通路
 └ 室內寬 ≥120CM
 └ 室外寬 ≥130CM
```
> 有層次又省字，比寫「其中包括…」快得多。

# PART D：交卷前檢核表（照這個順序打勾）

- [ ] 圖說項目**逐項打勾**，一項不缺

# PART E：一句話

> 他九年下來，**不是畫得比較快，是決策比較少**——版面、模組、句型都預先決定好，考場上只剩填內容。
> 而他之所以「專業」，是因為**知道哪些話不必用寫的**：圖面上的文字只有三種身分——
> **標籤（指認）、算式（證明）、故事（透視說明）**，其餘一律畫成圖。
