## 2. ★ 標題公式（超高 CP 值）

```
【大字主標 4–6 字】（書法感、佔右上角）
【副標一行：用「/」串起題目所有機能關鍵字】
```

**114 實例**：`韌性樂活方舟` ／ `防災/停車場/運動休閒/永續節能設計/健康交誼`

**為什麼有效**：副標那一行，**等於一秒鐘告訴考官「題目要的我全部都答了」**。寫的時間 30 秒，效果抵一整段文字。

**你的做法**：把題目的機能需求抄下來，用「/」串成一行，放在主標下面。

## 4. ★ 配置圖的四個關鍵動作

### 4.1 樓層機能直接標在量體上（不另畫平面）

114 實例，直接寫在配置圖的量體方塊裡：
```
RF 屋頂花園
6F 桌球館
5F 羽球場
4F 壁球場
3F 健身房・停車
2F 健康飲食・停車
1F 停車場・梯廳
```
> 這一招**同時回答了「垂直機能配置」與「空間組織」**，省下畫平面圖的時間。

### 4.2 藍色引線標註環繞四周（每則 5–15 字）

114 實例（環繞配置圖一圈）：
- 街道家具－提供停留休息
- 防火延燒帶－綠化＋防災
- 鄰里連徑－方便居民通行
- 退縮建築－減少壓迫感
- 一樓通行－東西連通
- 汽機車動線分流－提高安全性

> **格式：`名詞－效益`**，中間用破折號。短、準、專業。

### 4.3 開挖範圍用紅色虛線＋紅字標題

114 在配置圖右上角紅字寫「**開挖範圍**」，並用紅虛線框出地下室外緣。

### 4.4 量體計算寫成算式並打「ok!」

114 實例（放在左欄第④格軸測圖下方）：
```
建築面積 = 564＋960＋256＋118 = 1600 ㎡ ≤ 法定 3596×80% = 2876.8 ㎡ … ok!
容積面積 = 512×2＋960×6＋1450×2 = 10708 ㎡ ≤ 法定 3596×400%×1/3 = 17260 ㎡ … ok!
```
> 「**… ok!**」這三個字等於**自我檢核打勾**，考官一看就知道你算過也檢查過。

## 5. ★ 剖面圖的三個必備（你 114 失分的地方）

### 5.1 頂部標出「剖到的每一段」名稱與寬度

114 實例（剖面圖正上方橫排）：
```
商業區10R │人行退縮 2m 6m│園道│水渠│園道│人行退縮 2m 6m 4m│樂活休閒廣場│運動休閒＋停車場│鄰里巷弄│商業區3~4R│道路
```
> 這一行讓考官**不用猜你剖到哪裡**，是剖面圖專業度的第一指標。

### 5.2 右側每層標樓高數字

114 實例（剖面右緣，由上而下）：
```
RF ─
6F ─ 670
5F ─ 520
4F ─ 550
3F ─ 640
2F ─ 570
1F ─
B1F ─ 380
B2F ─ 290
```
> **每一層都有數字**。這正是你 114 被指出「樓高標示不清」的解法。

### 5.3 紅色中括號分類標註（散布剖面四周）

114 實例：
```
[室內環境] 綠建材・低VOC材料・確保健康
[日常節能] 升起遮陽・減少空調負荷・LED節能燈具・採高效能設備
[複層植栽] 增加生物多樣性
[廢棄物減量] 基地土方回填・減少廢棄土外運・施工期揚塵噪音污染防治
[基地保水] 透水鋪面・生態友善工法・滲透側溝/滲井・增加雨水入滲
[水資源] 雨水回收再利用
```
> **用中括號當分類標題**，一組 6 個貼在剖面周圍——這是「永續設計」最省時的表達法。

## 6. ★ 透視圖怎麼畫（113 的示範最好）

113 在**左欄第④格**放了兩張小透視，每張下方配 2–3 行文字：

> 「大樹木平台錨定了主廣場，為本設計的**精神中心**，逛街時可在此休憩、玩樂，並歡迎學生、民眾的到來。」
>
> 「深廊做為室內外的**中介空間**，連接活動的同時，提供遮蔭擋雨之功能，使人停留休息。」

**拆解這兩句的公式：**
```
〔場所名稱〕＋〔在設計中的角色〕＋〔誰在這裡〕＋〔做什麼〕
```

- 場所名稱：大樹木平台／深廊
- 角色：精神中心／中介空間
- 誰：學生、民眾
- 做什麼：休憩、玩樂、停留

> 💡 **這就是「透視要說故事」的具體寫法**——不是畫得美，是**文字把場所的意義講出來**。

### 6.1 各年透視的位置（可彈性）

| 年 | 透視位置 | 數量 |
|----|---------|------|
| 110 | 左欄第④格 | 1 張全區鳥瞰 |
| 111 | 中右直排 | 3 張 |
| 112 | 右下 | 1 張 |
| 113 | **左欄第④格** | 2 張＋文字說明 |
| 114 | （無獨立透視）| — |

> ⚠️ **誠實說明**：114 那張**沒有明顯的獨立外部空間透視**——他也可能在這項失分，靠其他項目補回來。所以「透視缺項」不是必死，但**能畫就一定要畫**（你 114 的檢討也指出這是最大缺口）。

## 7. ★ 申論區的排版（右欄）

### 7.1 結構
```
▮申論題
【小標題（橫線或方框強調）】
1. 論點
 └ 補充
2. 論點
 └ 補充
─────────────
〔等角透視小圖，用①②③…對應上面的條列〕
─────────────
〔細部剖面小圖 1–2 張〕
```

### 7.2 「└」符號的用法（他大量使用）

```
1. 人本交通
 └ 人車分離、連續步行動線，安全舒適
2. 室內外無障礙通路
 └ 室內寬 ≥120CM
 └ 室外寬 ≥130CM
```
> 「└」讓條列**有層次又省字**，比寫「其中包括…」快得多。**這個符號建議你直接學起來。**

### 7.3 110 的申論寫了真實案例（值得學）

110 題目要求「以你經手過的工作為例」，他寫了：
> 「以『**成大醫院門診大樓一樓鋪面改善案**』為例——透過 UX 觀點分析作業方式，發現現有人車混雜、車道非原先設計造成鋪面破裂、鋪面防滑度不足等問題，並提出改善提案。」

並配了**該案的平面示意圖＋剖面圖**（標大門、三角錐區隔、人行道、地下室範圍）。

> 💡 **這證實了 110/112 這類「用你的經驗舉例」題，一定要寫真實案例＋畫圖**。抄來的案例寫得再順都少一層說服力。

## 10. 四小時能畫完的真正原因（總結）

1. **版面固定**——五年同一套，不花時間想版面。
2. **模組預製**——6–8 個練熟的小圖與條列，考場直接調用。
3. **三點為度**——每格文字不超過 3 點，寫得完。
4. **標註公式化**——「名詞－效益」5–15 字，不假思索。
5. **算式打 ok!**——自我檢核一次到位。

> **一句話**：他不是畫得比較快，是**決策比較少**。版面、模組、句型都預先決定好，考場上只剩「填內容」。
