# 15 知識地圖（Concept Graph）

> 最後更新：2026-06-26｜可信度：★★★★☆
> 目的：把零散觀念連成網路——看一個題眼能牽出相鄰題眼、法規與設計手法，建立「整體感」。

## 節點 → 一句話 → 連到哪個題眼
| 節點 | 一句話 | 連到（10 題眼庫）|
|------|--------|----------------|
| 都市設計 | 設計建築「之間」的空間、導向公共利益 | 公益性、開放空間 |
| 公共空間/圖底 | 虛空是被設計的正空間 | 開放空間 |
| Placemaking | 名字＋活動＋使用者＝場所 | 開放空間、場所精神 |
| 人本尺度/Lynch | 路徑/邊界/節點/地標/區域 | 可及性、（立體化） |
| TOD | 車站為核、混合、可步行 | TOD、都市縫合 |
| 混合使用 | 垂直分層＋獨立核 | 混合使用、社會住宅 |
| 韌性 | 抵抗/回復/調適/再組織 | 韌性、防災 |
| 藍綠基盤 | 水＋綠＝滯洪＋降溫 | 藍綠基盤、微氣候 |
| 永續/綠建築 | EEWH 九大指標、實效非指標 | 永續 |
| 淨零 | 產＋省＋吸（碳匯） | 淨零 |
| 立體化 | 由地面延伸至立體、控天際線 | 立體化、公私協力 |
| 涵構/場所精神 | 紋理延續、記憶再現 | 場所精神、文資保存 |
| 都市縫合 | 修補被切割的都市裂縫 | 都市縫合 |

## 怎麼用
- 申論複合題（如韌性＋立體化）＝沿著相鄰節點「串成一個概念」（見 13 評分指南 25→28 分）。
- 名詞定義 → [references/名詞字典](../references/名詞字典.md)；題眼手法 → [10 題眼庫](./10-高頻題眼庫.md)。

## 考官視角 ｜ 高分關鍵 ｜ 常見扣分
- 考官視角：能把觀念連起來的人，答案有「整體感」。
- 高分關鍵：複合題眼成組答（韌性↔藍綠↔淨零；TOD↔混合↔立體化）。
- 常見扣分：單點背誦、節點之間無連結。
