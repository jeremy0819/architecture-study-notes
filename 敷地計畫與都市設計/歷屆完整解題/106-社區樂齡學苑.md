## 0.5 本年關鍵法源（必記）

> **🔑 關鍵法源：《建築技術規則》綠建築基準（微氣候／通風採光）＋《老人福利法》／高齡友善＋《建築物無障礙設施設計規範》**
> 申論考**微氣候**——依《建築技術規則》綠建築基準（通風、綠化、基地保水）改善；設計為**樂齡（高齡）**——高齡友善、無障礙、近保健，呼應《老人福利法》之長者照顧精神。**老樹**依各地《樹木保護自治條例》原地保留。
> **穿插句**：「依《建築技術規則》綠建築基準留通風廊道與綠化改善微氣候；依無障礙設施設計規範與高齡友善原則設平緩坡道、近保健室。」

## 2. 量體計算

```
基地 2,200 ㎡
建築面積上限 = 2,200 × 40% = 880 ㎡
容積樓地板   = 2,200 × 120% = 2,640 ㎡（低容積）
→ 可低層化、多留戶外活動與綠地（呼應高齡與微氣候）
```

## 4. 申論題（30 分）完整擬答

> ①都市**微氣候**形成原因、忽視之負面影響、都市設計對策；②如何以都市設計手法保存**空間形式與舊有都市記憶**。
> ①**套 [04 模板 5 韌性/環境變體]**；②**套 [04 模板 2 角色功能影響/保存]**。

**①微氣候**
- 成因：都市熱島（高蓄熱材料、人工發熱、綠地不足）、風場紊亂、日照遮蔽、濕度。
- 負面影響：通風不良→熱與污染累積；西曬熱島→能耗上升；風害；缺綠→生態與保水下降。
- 對策：**通風廊道、增綠覆與透水、建物退縮與棟距、遮蔭與騎樓、淺色高反射、水域綠軸降溫**。
```
〔微氣候對策 diagram〕
 夏南風→[通風廊道]→帶走熱  ☀西曬→遮蔭/淺色
 綠覆/透水→降溫保水   水綠軸→降溫
```

**②歷史記憶保存**
- 手法：紋理與街廓尺度延續、視覺廊道、新舊量體對話、**場所精神再現**、地名/事件詮釋（解說/地景再現）、活化再利用。

**法源穿插**：「依《建築技術規則》綠建築基準改善微氣候；歷史保存依《文化資產保存法》之精神延續紋理與場所精神。」

**小結**：微氣候靠藍綠與通風、記憶靠紋理與場所精神——兩者都應落在敷地配置上。（呼應樂齡戶外環境）

## 5. 設計主軸概念

> **主軸：「老樹樹下・樂齡客廳」**——以兩株老樹為戶外核心，建築低伏退讓、通風廊道穿越、地面抬高防淹，營造高齡友善的樹下客廳。

```
   一句話：  老樹為核 → 建築退讓低伏 → 通風廊道 → 地面抬高防淹
   臨20m道路(接送)  東→國小
   ┌──────────────────────────┐
   │ [樂齡學苑](低層,近電梯/保健) │
   │   🌳老樹A  ▒樹下客廳▒ 🌳老樹B │
   │   (戶外休閒核心,室外家具)     │
   └──────────────────────────┘
   夏南風通風廊道↗  地面抬高+透水(防淹)
```

## 通過關鍵（以考得過為主）
