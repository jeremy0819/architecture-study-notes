## 0. 本年關鍵法源（必記）

> 如同 114 的「停車場用地 → 停車空間**免計容積**」，每年都有一條**鎖住題型**的法源。108 的鎖鑰是**「容許使用」與「集會類防火避難」**。

> **🔑 關鍵法源：土地使用分區「容許使用」＋建築技術規則「使用類組與防火避難」**
> 本案位於**住宅區**，卻要設置「文化交流／社福／集會」性質設施——首須檢討該設施**是否屬住宅區之「容許使用」項目**（依《都市計畫法》土地使用分區管制、各都市計畫書土管規定；公益／社福／鄰里性集會多屬住宅區可附帶容許）。其次，講座／展演／共餐屬**集會類（D 類）使用**，依《建築技術規則》須符合**二方向避難、避難層直通出入口、步行距離**規範。
> **答題寫法**：「依《都市計畫法》土地使用分區管制，本案屬住宅區容許之公益服務設施；依《建築技術規則》集會類防火避難規定，設二方向避難與直通避難層出入口。」

> 另記：**緊急安置／心理諮商**需私密與獨立出入口（社福性質），無障礙依《建築物無障礙設施設計規範》。

```
基地 1,920 ㎡
建築面積上限 = 1,920 × 50% = 960 ㎡
容積樓地板   = 1,920 × 200% = 3,840 ㎡
→ 需求約 900 坪(≈2,970㎡)＋附屬，容積尚有餘裕；可低層化、多留半戶外與綠地
```

## 4. 申論題擬答（30 分）

> 題目：傳統敷地計畫偏技術安排；**Kevin Lynch《Site Planning》programming 觀**提醒空間計畫**非既定條件**，應放回基地檢討、修正、再定義；1970 後「**設計都市而非設計建築物**」、拉開開放空間「公共性」。請就此針對**鐵路高架化後之高架火車站與站前廣場改善**，以兩階段競圖「空間構想提案」，圖示輔助文字說明高架化後站前／站後的新可能性與限制及應考量面向。
> **用 [04 模板 3：流程／programming](../04-申論版面模板.md#模板-3都市設計的流程)**。

**破題**：敷地計畫不應將業主預擬之空間計畫（programming）視為既定條件，而應**放回基地環境檢討、修正、再定義**（Lynch）；鐵路高架化釋出地面層，正是重新定義站前／站後關係、拉開開放空間公共性的契機。

**一、programming 不是既定條件**：高架化後須重問「站前廣場該是什麼」——由純交通集散，**再定義為都市客廳**。

**二、機會（新可能性）**：地面層連通、消除鐵路阻隔、站前站後縫合、TOD 開發、橋下空間再利用。

**三、限制**：高架結構量體與陰影、噪音震動、橋下消極化、站前站後落差與權屬。

**四、空間構想面向**：人行縫合、廣場層級、無縫轉乘、防災避難、商業活化、橋下活化。

```
〔站前站後縫合 示意（剖向）〕
 站前廣場(都市客廳) ─ 高架站體 ─ 橋下活化 ─ 站後生活廣場
   ●人流 ════════════ 地面層連通(消除阻隔) ════════════ ●
```

**法源穿插**：「依都市設計『拉開開放空間公共性』之精神，並依《都市計畫法》細部計畫之都市設計管制，將站前廣場再定義為公共客廳。」

**小結**：以 programming 之再檢討，使高架化由「交通工程」升級為**縫合站前站後、還都市以公共客廳**的都市設計命題。（呼應設計題的「第二個家」公共性）

## 5. 設計主軸概念

> **主軸：「第二個家・公園客廳」**——建築退讓、把 1F 與南面三角公園縫成一個親民的「都市客廳」，私密社福（安置／諮商）藏於安靜側。

```
〔概念圖〕                           N↑
   西40m路(主人流/車入)
  ┌─────────────────────────┐
  │ [私密:安置/諮商] 獨立入口↑ │ 東:老公寓
  │ ◎大廳/共餐(面南公園)        │ (退讓呼應)
  │ ▒半戶外平台 → 三角公園      │
  └─────────────────────────┘
   南9m巷 ── 三角形社區公園(主開放面)
   地面抬高+透水+雨花園(淹水對策)
```

## 6. 圖面回應重點

**配置圖（1/300）**：人行主入口面南公園、車行出入口設西側 40 m 路；地面層架高＋透水；自行車地面、汽機車地下；垃圾清運走北巷。
**機能組織（水平＋垂直）**：1F 公共（大廳/共餐/展示）；2–3F 課程/辦公；**安置/諮商獨立核、安靜側**；祈禱室安靜獨立。
**剖面**：地面層抬高防淹、半戶外平台與公園銜接、低層量體呼應東側 4–5 層。
**透視**：南面公園─半戶外平台─大廳連續活動帶，加親子與多元族群人物。
