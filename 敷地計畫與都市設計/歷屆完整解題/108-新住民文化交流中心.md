## 0.5 本年關鍵法源（必記）

> **🔑 關鍵法源：土地使用分區「容許使用」＋建築技術規則「集會類防火避難」**
> 基地是**住宅區**卻要設文化交流／社福／集會設施——須先確認屬住宅區**容許使用**（依《都市計畫法》土地使用分區管制、各都市計畫書土管規定）；講座／展演／共餐屬**集會類（D 類）**，依《建築技術規則》須**二方向避難、直通避難層出入口、控制步行距離**。
> **穿插句**：「依《都市計畫法》土地使用分區管制，本案為住宅區容許之公益服務設施；依《建築技術規則》集會類防火避難，設二方向避難與直通避難層出入口。」
> 另記：**緊急安置／心理諮商**需私密與獨立出入口；無障礙依《建築物無障礙設施設計規範》。

## 2. 量體計算

```
基地 1,920 ㎡
建築面積上限 = 1,920 × 50% = 960 ㎡
容積樓地板   = 1,920 × 200% = 3,840 ㎡
機能估 ≈ 900 坪(≈2,975㎡)＋服務 → 容積足夠
```
**考過態度**：需求不大，**刻意低層化（約 3–4 層）、多留南面前埕與半戶外**，把「第二個家」的親民感畫出來，而非塞滿量體。

## 4. 申論題（30 分）完整擬答

> 題目：Lynch《Site Planning》**programming 觀**（空間計畫非既定條件，放回基地檢討）；1970 後「設計都市而非設計建築物」、拉開開放空間公共性。針對**鐵路高架化後高架火車站與站前廣場改善**，兩階段競圖「空間構想提案」，圖示輔助文字說明站前／站後新可能性與限制與應考量面向。
> **套 [04 模板 3：流程／programming](../04-申論版面模板.md#模板-3都市設計的流程)**；先寫、附 diagram。

**破題**：敷地計畫不應將業主預擬之 programming 視為既定條件，而應**放回基地檢討、修正、再定義**（Lynch）；鐵路高架化釋出地面層，正是重新定義站前／站後、拉開開放空間公共性的契機。

**一、programming 再檢討**：高架化後重問「站前廣場該是什麼」——由純交通集散**再定義為都市客廳**。
**二、機會**：地面層連通、消除鐵路阻隔、站前站後縫合、TOD 開發、橋下空間再利用。
**三、限制**：高架結構量體與陰影、噪音震動、橋下消極化、站前站後落差與權屬。
**四、空間構想面向**：人行縫合、廣場層級、無縫轉乘、防災避難、商業活化、橋下活化。

```
〔站前站後縫合 示意（剖向）〕
 站前廣場(都市客廳) ─ 高架站體 ─ 橋下活化 ─ 站後生活廣場
   ●人流 ════ 地面層連通(消除阻隔) ════ ●
   〔上〕高架月台   〔下〕TOD轉乘/商業/避難
```
**法源穿插**：「依都市設計拉開開放空間公共性之精神、《都市計畫法》細部計畫之都市設計管制，將站前廣場再定義為公共客廳。」
**小結**：以 programming 再檢討，使高架化由「交通工程」升級為**縫合站前站後、還都市以客廳**的都市設計命題。（呼應設計題「第二個家」的公共性）
