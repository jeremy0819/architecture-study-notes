## 0.5 本年關鍵法源（必記）

> **🔑 關鍵法源：《國民中小學設施設備基準》＋《幼兒園及其分班基本設施設備標準》＋公共設施用地多目標使用**
> 國小＋附屬幼兒園＋社區中心＋公園於同一園區複合——教室／運動場依**設施基準**；**幼兒活動室設 1–3 樓、不得設於地下層**；校園與公園/社區之複合屬**公共設施用地多目標使用**。
> **穿插句**：「依《國民中小學設施設備基準》與《幼兒園基本設施設備標準》配置教學與幼托空間；依公共設施用地多目標使用，校、社、公園資源共享。」

## 5. 設計主軸概念

> **主軸：「校・社・園共享聚落」**——公園為核縫合三者，教學核在內、社區中心在外緣、幼兒園獨立。

```
   一句話：  公園為核 → 教學在內 → 社區在外緣 → 幼兒獨立 → 假日共享
   ┌────────────────────────────┐
   │ [社區活動中心](外緣,假日開)  │
   │   ░░公園綠地(縫合核心)░░     │
   │ [國小教學核] [運動場]        │
   │ [幼兒園](獨立低層,接送避車彎) │
   └────────────────────────────┘
```
