## 0.5 本年關鍵法源（必記）

> **🔑 關鍵法源：《建築技術規則》使用類組（住宿 H／集會 D）防火避難（＋綠建築基準）**
> 青年旅舍／住宿（H 類）＋文化交流（展演、工作坊＝集會 D 類）複合——依《建築技術規則》**使用類組之防火區劃與二方向避難**；住宿與集會動線分流。永續依綠建築基準。
> **穿插句**：「依《建築技術規則》使用類組防火避難，住宿與展演工作坊分區劃、各設二方向避難；以環中庭配置促國際交流。」

---

## 1. 審題：條件清單

| 項 | 內容 | 圖面回應 |
|----|------|---------|
| 議題 | 國際文化交流與社群營造、多元文化融合、**開放共享與適度隱私** | 環中庭、公私分層 |
| 機能 | 青年旅舍／住宿＋文化交流（展演、工作坊）＋戶外活動 | 村落配置 |

---

## 2. 量體（題型重點）

```
村落式配置：
- 住宿單元環抱中庭(社群感)
- 展演/工作坊對外(共享)、住宿較內(隱私)
- 連橋步道串聚落
```

---

## 3. 課題與對策

| 課題 | 對策（落圖）|
|------|-----------|
| 國際交流/社群 | **環中庭村落**、共享廚房/客廳、戶外活動場 |
| 開放共享 vs 隱私 | 展演/工作坊對外低層；住宿單元內側/上層、門禁 |
| 多元文化 | 彈性展演空間、多元飲食/集會 |
| 動線分流 | 住宿（H）與集會（D）分區劃、各二方向避難 |

---

## 4.（本年無獨立申論）

> 設計說明可穿插：使用類組防火避難、青年共享、綠建築。

---

## 5. 設計主軸概念

> **主軸：「環中庭聚落・共享村」**——住宿單元環抱共享中庭、展演工作坊對外，連橋串成國際青年村。

```
   一句話：  住宿環中庭 → 展演對外 → 連橋串聚落 → 公私分層
   ┌──────────────────────────┐
   │ [展演/工作坊](對外,共享,低層)│
   │   ░共享中庭/戶外活動░       │
   │ [住宿單元]環抱(內側/上層,門禁)│
   │   ═連橋步道═串聚落          │
   └──────────────────────────┘
```

---

## 圖面回應（必備圖面）

**村落配置（環中庭）**：住宿環抱、展演對外、連橋、戶外活動場、人車分流。
**主要空間平面**：住宿單元、共享廚房/客廳、展演工作坊。
**剖面或透視（關鍵）**：**連橋步道、公私分層、中庭氛圍**。
```
〔剖面/透視〕[展演對外] ░中庭░ [住宿環抱] ═連橋═
 公私分層：下/外=共享、上/內=隱私
```

## 通過關鍵（以考得過為主）

> **概念**「環中庭聚落・共享村」；以中庭營造國際青年社群、展演對外住宿藏內、連橋串聚落。失分：住宿展演混雜無公私層次、無中庭社群核、動線不分流。
