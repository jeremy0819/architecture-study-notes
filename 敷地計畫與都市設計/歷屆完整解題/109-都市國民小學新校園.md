## 0. 本年關鍵法源（必記）

> **🔑 設計法源：「國民中小學設施設備基準」＋幼兒園設施設備標準**
> 校園是**規範驅動**的題型：普通教室、專科教室、運動場（短跑直道、操場）、保健室、圖書館之**面積與配置**有基準可循；**幼兒園活動室依序設於 1–3 樓、不得設於地下層**（《幼兒園及其分班基本設施設備標準》）。
> **答題寫法**：「依《國民中小學設施設備基準》配置普通／專科教室與運動場；依《幼兒園基本設施設備標準》，幼兒活動室設於低樓層、不設地下層並留家長接送避車彎。」

> **🔑 申論法源（本年直接考）：都市更新條例 × 都市危險及老舊建築物加速重建條例**
> 申論三小題即此二法之意旨、內容、敷地都設注意點與**異同**——是本年**必背對照表**（見 §4）。

## 1. 審題：條件清單

| 項 | 內容 |
|----|------|
| 基地 | 完整街廓校地**約 4 公頃（40,000 ㎡）** |
| 周界 | 西鄰 15 m、東鄰 30 m、南北各 10 m 道路；北高南低坡約 1% |
| 都設準則 | **境界線退縮 5 m 連續林木綠地**（盡量保留連續性）|
| 涵構 | 周遭低矮社區依**危老**往高層（西側已 12–16 層）|
| 配比 | **校舍 30%／運動 30%／綠地庭園步道 40%** |
| 分區內容 | 國小＋幼兒園＋社區長青學院＋時段共享（綜合活動中心含標準籃球場、圖書館、戶外運動場、停車 100 含地面 ≥20）|
| 圖說配分 | **分區規劃圖 25＋國小規劃設計圖 35＋透視 10** |

---

## 2. 量體與分區計算

```
基地 40,000 ㎡
校舍 30% = 12,000 ㎡ ｜ 運動 30% = 12,000 ㎡ ｜ 綠地步道 40% = 16,000 ㎡
→ 4 公頃大基地：先 zoning(分區) 再設計；配分集中在分區圖(25)＋國小圖(35)
```

## 3. 課題與對策

| 課題 | 對策（落圖）|
|------|-----------|
| 4 公頃大基地 | **先分區（zoning）**：教學區／運動區／社區共享區／綠環 |
| 退縮 5 m 連續林帶 | 串成**校園綠環**，保持連續、兼防護與緩衝 |
| 校社融合、時段共享 | 社區共享機能（活動中心、圖書館）置**外緣**，假日可獨立開放、與校核分離 |
| 學齡分齡安全 | 幼兒園獨立區（低樓層）、高低年級分區、無圍牆但**動線分層管制** |
| 周遭危老高層化 | 校園以綠環與低層退讓，緩和高層壓迫、爭取日照 |
| 北高南低 1% | 順坡配置運動場於較平處、處理排水 |

## 4. 申論題擬答（30 分）：都更 vs 危老

> **用 [04 模板 1：法令規章（比較表）](../04-申論版面模板.md#模板-1法令規章比較型)**。表格本身就是份量。

**都市更新條例：精神**＝以**更新單元、權利變換**進行**整體**再開發，提升機能與公益。
**危老重建條例：精神**＝就**個別基地**加速**重建**、提升耐震與居住安全。

| 項目 | 都市更新條例 | 危老重建條例 |
|------|-------------|-------------|
| 性質 | 更新（整建/維護/重建）| **重建**為主 |
| 範圍 | 須劃定**更新單元** | **個別基地**、免劃更新地區 |
| 機制 | **權利變換**、整體規劃 | 同意後重建、程序簡便 |
| 誘因 | 容積獎勵、稅捐減免 | **時程獎勵**＋容積、稅捐 |
| 規模 | 較大、街廓尺度 | 較小、單棟 |
| 敷地/都設注意 | 整體開放空間、公益設施、留設縫合 | 個別退縮、鄰棟日照、避免突兀高層 |
| **共同點** | 加速老舊重建、提升耐震與居住品質、給容積／稅捐誘因 | （同左）|

**法源穿插**：「依《都市更新條例》以更新單元與權利變換整體規劃；依《都市危險及老舊建築物加速重建條例》就個別基地加速重建。」

**小結**：二法互補——都更治「**整體街廓**」、危老治「**個別單棟**」；於本校周邊高層化脈絡下，校園應以綠環與退讓回應高層、維護學童日照與安全。（呼應設計）

## 5. 設計主軸概念

> **主軸：「綠環校園・校社共融」**——5 m 退縮林帶串成連續綠環，教學核在內、社區共享在外緣，假日對外不擾教學。

```
〔分區概念〕                         N↑
  ┌───────綠環(退縮5m連續林帶)───────┐
  │ [社區共享:活動中心/圖書館]外緣→假日開放│ 東30m
  │   ┌──────────────────────┐       │
  │   │ [國小教學核] 普通/專科教室│       │
  │   │ 中庭   [運動區:操場/球場]│       │
  │   └──────────────────────┘       │
  │ [幼兒園]獨立區(低樓層,接送避車彎)   │
  └────────────────────────────────┘
   西15m(已12-16層高層)   南10m(北高南低1%)
```

## 6. 圖面回應重點

**分區規劃圖（25 分・重點）**：四區 zoning＋綠環＋人車分流＋社區共享外緣＋停車（地面 ≥20）；標配比 30/30/40。
**國小規劃設計圖（35 分・重點）**：普通/專科教室單元、運動場、保健室近出入口、無障礙、避難集合場（操場兼地震避難）。
**幼兒園**：獨立區、活動室 1–3F 不設地下、接送避車彎。
**透視（10 分）**：綠環＋無圍牆校園＋學童活動。
