## 4. 申論題（30 分）完整擬答：都更 vs 危老

> **套 [04 模板 1：法令規章（比較表）](../04-申論版面模板.md#模板-1法令規章比較型)**。表格本身就是份量。

**都市更新條例・精神**：以**更新單元、權利變換**進行**整體**再開發。
**危老重建條例・精神**：就**個別基地**加速**重建**、提升耐震與安全。

| 項目 | 都市更新條例 | 危老重建條例 |
|------|-------------|-------------|
| 性質 | 更新（整建/維護/重建）| **重建**為主 |
| 範圍 | 須劃**更新單元** | **個別基地**、免劃更新地區 |
| 機制 | **權利變換**、整體規劃 | 同意後重建、程序簡便 |
| 誘因 | 容積獎勵、稅捐減免 | 容積、稅捐；**時程獎勵 114.5.12 已歸零→規模獎勵** |
| 規模 | 較大、街廓尺度 | 較小、單棟 |
| 敷地/都設注意 | 整體開放空間、公益設施、縫合 | 個別退縮、鄰棟日照、避免突兀高層 |
| 環境影響 | 整體提升但施工衝擊大、需安置 | 單點更新快、但易破壞天際線連續 |
| **共同點** | 加速老舊重建、提升耐震與居住品質、給容積／稅捐誘因 | （同左）|

**法源穿插**：「依《都市更新條例》以更新單元、權利變換整體規劃；依《都市危險及老舊建築物加速重建條例》就個別基地加速重建。」

**小結**：都更治「**整體街廓**」、危老治「**個別單棟**」；本校周邊高層化下，校園以綠環與退讓回應高層、維護學童日照安全。（呼應設計）

## 5. 設計主軸概念

> **主軸：「綠環校園・校社共融」**——5 m 退縮林帶串成連續綠環，教學核在內、社區共享在外緣，假日對外不擾教學。

```
   一句話：  綠環縫四周 → 教學核居中 → 共享放外緣 → 幼兒獨立
   西15m(已12-16F) ║ 綠環 ║ 教學核+運動 ║ 綠環 ║ 東30m
   高層→退讓爭日照 ║(林帶)║ 幼兒獨立低層 ║(林帶)║
```
