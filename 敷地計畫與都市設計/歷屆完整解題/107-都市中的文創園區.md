## 0.5 本年關鍵法源（必記）

> **🔑 關鍵法源：《文化資產保存法》（歷史建物三合院）＋《文化創意產業發展法》**
> 基地旁有**歷史建物（一層三合院）**——依《文化資產保存法》保全其紋理與前埕、視覺廊道；文創園區之產業屬性呼應《文化創意產業發展法》。**3.6 m 無遮簷人行道**為地方都審準則（依題目）。
> **穿插句**：「依《文化資產保存法》維護三合院前埕與視覺廊道、新量體低層退讓；依《文化創意產業發展法》營造展演與工作坊聚落。」

## 4. 申論題（30 分）完整擬答：都市／城鄉廣場

> ①廣場的定義與種類；描繪一處台灣廣場（形成原因/變遷/涵構互動/不同時間活動/型態視野）。②繪該廣場**配置示意圖＋剖面示意圖**，說明**成功因素與未來期待**。
> **套 [04 模板 2/G 公共空間]**，**本題必附廣場配置圖＋剖面圖**。

**①廣場定義與種類**：廣場＝都市中**界定明確、供公共活動的開放虛空**；種類：市政/紀念廣場、宗教廟埕、商業/市集廣場、交通集散廣場、社區鄰里廣場。

**舉例（如廟埕）**：形成（廟宇信仰中心）→變遷（市集/節慶/日常）→涵構（廟、老街、樹）→活動（晨運、市集、廟會）→型態（圍塑感、人尺度、視軸對廟）。

**②成功因素**（附圖）：**圍塑感（界定）、可及性、人本尺度、混合活動、遮蔭與座椅、與涵構連結**。
```
〔廣場配置＋剖面示意〕
 平面: 建築圍塑→廣場→對景(廟/地標)，邊緣咖啡/座椅
 剖面: D/H 比例適中(圍塑不壓迫)，喬木遮蔭，人活動
```

**法源穿插**：「依都市設計拉開開放空間公共性之精神，廣場與三合院前埕、人行道串為連續公共活動帶。」

**小結**：成功廣場＝**圍塑＋可及＋人本＋混合活動＋涵構連結**；正落實於本案文創廣場。（呼應設計）

## 5. 設計主軸概念

> **主軸：「三合院前埕・文創廣場」**——以三合院前埕與 600 ㎡ 室外廣場為核，文創量體低層圍塑、串連 3.6 m 人行道成連續活動帶。

```
   一句話：  三合院前埕為核 → 文創低層圍塑 → 600㎡廣場 → 人行道串活動帶
   ┌──────────────────────────┐
   │ [文創工作坊/展示/演講](低層圍塑)│
   │   ▒室外多功能廣場600(臨時展場)▒ │
   │   卍三合院(一層) ▒前埕▒ 🌳既有樹│
   └──────────────────────────┘
   ▒3.6m無遮簷人行道▒(連續活動帶)
   地下停車車道口→避開廣場/三合院
```
