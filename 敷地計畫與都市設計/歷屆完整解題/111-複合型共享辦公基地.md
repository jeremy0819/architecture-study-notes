## 0. 本年關鍵法源（必記）

> **🔑 關鍵法源：建築技術規則「使用類組與防火區劃」（住辦垂直分流）＋《住宅法》**
> 本案為**住辦混合**（共享辦公 G 類＋出租住宅 H 類）——依《建築技術規則》**不同使用類組須防火區劃、各自獨立垂直動線（樓電梯核分設）**，這是住辦複合的鎖鑰（如同 114 的免計容積）。出租住宅之經營可呼應**《住宅法》**包租代管／社會住宅之政策精神。
> **答題寫法**：「依《建築技術規則》使用類組與防火區劃，辦公與住宅各設獨立出入口與垂直動線；出租住宅依《住宅法》精神導入。」

> 另記：法定停車依《建築技術規則》附設、地下化；3 m 無遮簷人行道為**地方都審準則**（依題目給定）。

## 4. 申論題擬答（30 分）：韌性城市＋雙向六線道

> 題目：①「韌性城市」概念與**都市設計關鍵思考要素** ②設計一條**雙向六線道主要道路**，導入提昇韌性、友善使用者構想（圖文）。
> **用 [04 模板 5：韌性城市](../04-申論版面模板.md#模板-5韌性城市)**。

**破題**：韌性城市＝面對衝擊（洪水/地震/熱浪/疫情）的**抵抗、回復、調適、再組織**能力；都市設計以藍綠基盤與彈性空間落實。

**一、韌性關鍵要素**：藍綠基盤、海綿城市（透水/滯洪/入滲/再利用）、多元備援、分散式系統、彈性空間、社區自主防災。

**二、雙向六線道斷面設計**（圖文）：
```
〔街道斷面〕
 人行|複層綠帶|自行車|━車道×3━|分隔島|━車道×3━|綠帶|人行
 + 透水鋪面 + 行道樹遮蔭 + 側溝滯洪 + 無障礙/座椅(友善)
```
- **韌性**：透水鋪面降逕流、行道樹降溫、側溝/雨花園滯洪、分隔島藍綠串聯。
- **友善使用者**：連續無障礙、座椅、遮蔭、自行車道、過街庇護島。

**法源穿插**：「依《水利法》出流管制設側溝滯洪；依《建築物無障礙設施設計規範》設連續通路。」

**小結**：韌性街道＝把道路從「車的通道」升級為**藍綠基盤＋人本廊道**。（呼應設計的 3 m 人行道與埤塘藍綠基盤）

## 5. 設計主軸概念

> **主軸：「共享聚落・埤塘客廳」**——辦公與住宅環抱面埤塘的共享中庭，把最好的西南面讓給開放交流。

```
〔概念圖〕                        N↑
   東北 國小(後門接送避車彎)
  ┌──────────────────────┐
  │ [出租住宅] 獨立門廳↑    │ 既有樹木保留
  │   ┌──共享中庭──┐       │ (中庭核心)
  │   │ 交流/展示   │       │
  │ [共享辦公] 獨立門廳↑    │
  └────────●開放交流────┘
   西南 埤塘公園(假日人潮)←面此開放
   3m無遮簷人行道環基地
```

## 6. 圖面回應重點

**地面層全區配置**：辦公/住宅出入口分離；面西南埤塘開共享交流＋半戶外；國小側避車彎；3 m 人行道連續；停車地下、標車道出入口。
**住宅標準層平面**：套房/一房/二房房型配置、獨立垂直動線核、採光通風。
**剖面兩向**：住辦防火區劃與垂直分流、屋頂綠化光電、街道斷面回應韌性。
**透視**：埤塘─共享交流平台的活動氛圍。
