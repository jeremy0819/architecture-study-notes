## 0.5 本年關鍵法源（必記）

> **🔑 關鍵法源：《文化資產保存法》＋《都市更新條例》**
> 基地核心是**法定古蹟（媽祖廟）周邊的住商更新**——依《文化資產保存法》，古蹟應就**定著土地與周邊環境景觀**予以保全（得劃定古蹟保存用地／保存區、訂保存計畫，管制周邊建築之高度、量體與色彩）；住商更新則依《都市更新條例》以**更新單元、權利變換**整體開發。
> **穿插句**：「依《文化資產保存法》維護古蹟及其環境景觀，管制周邊量體與視覺廊道；依《都市更新條例》以更新單元整體開發住商。」

## 2. 量體（題型重點）

```
古蹟周邊以「高度與量體退縮」為核心：
- 古蹟前留設前埕／廣場、維持視覺廊道
- 新建量體由古蹟向外「漸高」(近古蹟低、遠處高)
- 容積以都更整體規劃調配（精確值依原卷）
```

---

## 3. 課題與對策

| 課題 | 對策（落圖）|
|------|-----------|
| 古蹟保存 vs 都更 | **古蹟前埕保留、視覺廊道淨空**；新量體退離 |
| 視覺廊道與尺度 | 由古蹟向外**階梯漸高**、天際線過渡 |
| 新舊對話 | 紋理延續、材質/色彩呼應、低層裙樓貼古蹟 |
| 住商混合 | 1F 商業連續街面、上層住宅、人車分流 |

## 4.（本年無獨立申論）

> 97–104 為純設計題；觀念論述併入「規劃設計說明」。**設計說明可穿插**：依《文化資產保存法》之古蹟環境維護、依《都市更新條例》之整體開發。

## 5. 設計主軸概念

> **主軸：「古廟前埕・新舊共生」**——以古蹟前埕與視覺廊道為核心，新建住商量體退讓、由低向高漸層，與古廟對話。

```
   一句話：  古廟留前埕 → 視廊淨空 → 新量體退讓漸高 → 紋理延續
   ┌──────────────────────────┐
   │ [新住商高層](遠古蹟,較高)  │
   │ [中層裙樓](過渡)           │
   │ ▒前埕廣場▒  卍媽祖廟(古蹟,低)│←視覺廊道淨空
   └──────────────────────────┘
```

## 圖面回應（必備圖面）

**總平面**：古蹟與新建關係、**前埕/開放空間**、視覺廊道、人車分流。
**開發分區示意**：古蹟保存區（緩衝）／住商更新區，量體分布。
**街道斷面（關鍵）**：古蹟脊高 vs 新建高度——**由古蹟向外階梯漸高**、天際線過渡。
```
〔街道斷面〕
 卍古廟(低) ─前埕─ 裙樓(中) ─ 住商(高)
 視覺廊道淨空↗   天際線階梯過渡
```
**透視**：古廟前埕的人本場景（香客、市集、樹蔭）。

## 通過關鍵（以考得過為主）

> **概念**「古廟前埕・新舊共生」；**英雄條件**＝古蹟，全卷由它退讓、漸高、留視廊。街道斷面標清楚新舊高度過渡是得分點。失分：新量體壓迫古蹟、視覺廊道被擋、無前埕。
