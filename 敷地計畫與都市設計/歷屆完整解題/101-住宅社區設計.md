## 0.5 本年關鍵法源（必記）

> **🔑 關鍵法源：《建築技術規則》（棟距／日照間距、採光通風）＋《住宅法》**
> 住宅社區的核心是**居住品質**——依《建築技術規則》建築設計施工編之**日照、棟距（鄰幢間隔）、開窗採光、通風**規定確保各戶日照通風；社區營造呼應《住宅法》居住權益。
> **穿插句**：「依《建築技術規則》之日照間距與棟距規定確保各戶採光通風；以人車分流與中庭營造永續鄰里。」

## 2. 量體（題型重點）

```
中低層集合住宅：
- 棟距足夠(依日照間距)、坐向爭取日照通風
- 地面人車分流、地下停車
- 中庭/遊樂場/會館為鄰里核心
```

---

## 3. 課題與對策

| 課題 | 對策（落圖）|
|------|-----------|
| 日照通風棟距 | **棟距≥日照間距**、量體錯落、南向爭取日照 |
| 人車分流 | 車輛地下化、地面留人行與中庭、車道口集中 |
| 鄰里關係 | 中庭/遊樂場/會館為**社交核心**、半公共層次 |
| 永續社區 | 透水、綠化、通風廊道、雨水回收 |

## 5. 設計主軸概念

> **主軸：「中庭鄰里・人車分流」**——住宅棟錯落爭日照、環抱共享中庭，車輛地下化把地面還給人。

```
   一句話：  棟距爭日照 → 量體錯落 → 中庭為核 → 人車分流
   ┌──────────────────────────┐
   │ [住宅棟A]   [住宅棟B](錯落) │
   │   ░中庭/遊樂場/會館░        │
   │ [住宅棟C]   [住宅棟D]       │
   └──────────────────────────┘
   棟距≥日照間距；地面人行、地下停車
```

## 通過關鍵（以考得過為主）

> **概念**「中庭鄰里・人車分流」；剖面標**棟距與日照角**是專業展現。中庭當社交核、車輛地下化。失分：棟距不足採光差、人車混流、中庭淪剩餘空地。
