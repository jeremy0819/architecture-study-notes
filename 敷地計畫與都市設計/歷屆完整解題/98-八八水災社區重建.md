## 0.5 本年關鍵法源（必記）

> **🔑 關鍵法源：《災害防救法》＋《水土保持法》＋（時效）莫拉克颱風災後重建特別條例**
> 八八水災重建——**安全選址、防洪標高、避難**是核心：依《災害防救法》建立防救災與避難體系；依《水土保持法》就坡地／集水區做水土保持與安全評估。
> ⚠️ **時效注意**：《莫拉克颱風災後重建特別條例》為**限時特別法（98 公布、103 落日失效）**，僅當年情境適用；現今作答以《災害防救法》《水土保持法》《國土計畫法》（安全國土／避災）為準。
> **穿插句**：「依《災害防救法》建立避難與防救災動線；依《水土保持法》就集水區安全評估後選址，永久屋抬高防洪標高。」

---

## 2. 量體（題型重點）

```
重點不在容積，而在「安全」與「社群」：
- 永久屋以「組團(cluster)」配置、保留部落鄰里關係
- 地坪抬高至防洪標高以上、設滯洪/排水
- 留避難空間與避難動線
```

---

## 3. 課題與對策

| 課題 | 對策（落圖）|
|------|-----------|
| 防洪安全 | **地坪填築抬高至防洪標高**、滯洪池、排水分區、退離河岸 |
| 遷村選址 | 避開土石流/淹水潛勢、坡地安全評估（水保）|
| 原鄉文化 | 部落空間紋理、廣場/聚會所、農園延續生計 |
| 社群凝聚 | **組團住宅環中央活動中心**、共享綠地 |
| 分期/購地 | 分期範圍示意 |

## 5. 設計主軸概念

> **主軸：「抬高的部落・安全聚落」**——永久屋組團環抱活動中心、地坪抬高防洪、保留原鄉紋理與農園。

```
   一句話：  安全選址 → 地坪抬高 → 組團聚落 → 活動中心為核 → 農園生計
   ~~河岸(退離)~~ ▒滯洪/緩衝綠帶▒
   ┌──────────────────────────┐
   │ [組團A] ┌活動中心/聚會所┐ [組團B]│
   │         │  中央廣場     │        │
   │ [農園]  └──────────────┘ [組團C]│
   └──────────────────────────┘
   (全區地坪抬高至防洪標高以上)
```

---

## 圖面回應（必備圖面）

**重建社區配置**：住宅組團、活動中心、避難空間、農園、退離河岸＋緩衝綠帶。
**分期／購地範圍示意**：開發分期。
**剖面（關鍵）**：**填築抬高、防洪標高、排水**。
```
〔剖面〕河岸 ~~~ 緩衝綠帶 ── 抬高地坪(永久屋) ──
 防洪標高▽━━━填築━━━ 滯洪/排水
```
**透視**：部落廣場與聚會所、原鄉氛圍。

## 通過關鍵（以考得過為主）

> **概念**「抬高的部落・安全聚落」；**英雄條件**＝防洪安全＋原鄉文化。剖面一定要畫**填築抬高＋防洪標高**；配置用組團保留部落鄰里。失分：永久屋排排站無社群感、沒處理防洪標高、緊貼河岸。
