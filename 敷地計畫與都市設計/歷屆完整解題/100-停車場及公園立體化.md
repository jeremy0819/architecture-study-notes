## 0.5 本年關鍵法源（必記）

> **🔑 關鍵法源：《都市計畫公共設施用地多目標使用辦法》（立體／多目標使用）**
> 「停車場＋公園**立體化**合併使用」——正是公共設施用地**立體多目標使用**的典型；停車收於地下／低層、公園綠地置於其上（覆土植栽）。與 113、114 同一法源家族。
> **穿插句**：「依《都市計畫公共設施用地多目標使用辦法》，停車場與公園立體複合：車庫下藏、綠地在上，覆土植栽確保綠量。」

## 2. 量體（題型重點）

```
立體分層：
- 地下/低層：公共停車(車道、機械或自走)
- 地面/頂層：都市公園(覆土植栽,喬木需足夠覆土深)
- 覆土深度:喬木 >1.5m、灌木 >0.6m、地被 >0.3m
- 設通風天井/採光,解地下停車通風
```

---

## 3. 課題與對策

| 課題 | 對策（落圖）|
|------|-----------|
| 土地複合＋綠地保存 | **停車地下化、公園置其上**，綠量不減反增 |
| 覆土植栽 | 喬木區覆土 ≥1.5 m、結構承重與排水層 |
| 地下通風採光 | **通風天井、下沉庭園**引光與換氣 |
| 動線衝突 | 車道出入口與公園人行**分流**、車口開次要道路 |
| 防洪 | 地下停車出入口防水高程、滯洪 |

## 5. 設計主軸概念

> **主軸：「車庫下藏・綠在其上」**——把停車收進地下/低層，地面交還都市公園，以通風天井串聯上下。

```
   一句話：  停車下藏 → 公園在上 → 覆土植栽 → 天井引光換氣
   ░░░░都市公園(覆土植栽/喬木)░░░░ ← 地面/頂層
   ┌───天井───┐      ┌───天井───┐
   │ 停車場(地下/低層,自走/機械)    │
   └────────────────────────────┘
   車道出入口→次要道路(與公園人行分流)
```

## 圖面回應（必備圖面）

**立體利用剖透視（關鍵）**：上公園、下停車、通風天井、覆土層。
```
〔剖面〕
 公園綠地(喬木) ▒覆土≥1.5m▒ ━━結構板/排水層━━
 ┌天井┐ 停車層(通風採光) ┌天井┐
 防水閘 地下停車出入口(防水高程)
```
**停車與公園平面**：兩層平面對位、車道/人行分流。
**剖面**：層高、通風天井、覆土深度標註。
**透視**：屋頂公園的人本活動。
