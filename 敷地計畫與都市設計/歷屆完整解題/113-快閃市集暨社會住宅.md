## 0. 從圖面回應答案（本科鐵則）

「未標示在圖上不計分」。本案靈魂是**公（市集）私（社宅）垂直分層**＋**南側廟宇涵構**。圖說特別要**一樓平面＋開挖範圍**。以考得過為主：分層清楚、廟埕共生、廣場兼滯洪呼應申論。

## 0.5 本年關鍵法源（必記）

> **🔑 關鍵法源：《都市計畫公共設施用地多目標使用辦法》＋《住宅法》**
> 基地為**市場（公共設施）用地**，卻要疊入**社會住宅與社工站**——須靠**《都市計畫公共設施用地多目標使用辦法》**（公設用地得**立體／多目標複合使用**）才合法；導入之**社會住宅**依**《住宅法》**（只租不售、保障弱勢比例、包租代管）。
> **穿插句**：「依《都市計畫公共設施用地多目標使用辦法》，市場用地立體多目標複合社會住宅與社福；社會住宅依《住宅法》只租不售並保障弱勢入住。」
> 另記：減洪（呼應申論）→《水利法》出流管制；西側國小→人車安全。

## 2. 量體計算

```
基地 3,500 ㎡
建築面積上限 = 3,500 × 45% = 1,575 ㎡
容積樓地板   = 3,500 × 300% = 10,500 ㎡
社宅 150 戶(1房90+2房60) → 上層精算住宅樓地板；低層市場挑高
```
**考過態度**：低層市集要**熱鬧、可彈性**；上層社宅要**獨立門禁、有尊嚴**；南面退讓給廟埕。

## 4. 申論題（30 分）完整擬答：水文調查＋減洪

> **套 [04 模板 5：韌性城市（水文變體）](../04-申論版面模板.md#模板-5韌性城市)**。

**破題**：排水管網短期難擴充，須以「**留、滯、滲、用**」於**都市設計**與**敷地計畫**兩層面分散滯蓄。

**一、水文調查項目**：降雨強度與頻率、集水區範圍、地表逕流係數、地下水位、**淹水潛勢圖**、排水路與排水分區、土壤入滲率、歷史淹水紀錄。

**二、都市設計層面減洪**：保留滯洪綠地與藍帶、降低不透水率、雨水分區滯蓄、退縮藍綠廊道、低衝擊開發（LID）。

**三、敷地計畫層面減洪**：基地保水（透水鋪面/雨花園/生態滯洪池）、屋頂與中水回收、地面層架高與防水閘、地下室出入口防水高程、基地內逕流分流。

```
〔集水區→基地 逕流分流〕
 集水區→逕流│→透水鋪面/雨花園→生態滯洪池→排程放流
            │→屋頂滯洪/雨水回收→中水
 戶外市集廣場 = 平時市集 / 雨時滯洪(彈性空間)
```

**法源穿插**：「依《水利法》出流管制之精神，基地滯蓄後再放流，不直接排入公共排水溝。」

**小結**：水患減洪＝**把基地變海綿**；戶外市集廣場兼滯洪、平災兩用。（呼應設計）

## 5. 設計主軸概念

> **主軸：「市集疊聚落・廟埕共生」**——低層市集/快閃/廣場熱鬧對外、上層社宅獨立門禁；南面廟宇開廟埕廣場共享樹蔭。

```
   一句話：  市集疊在下 → 社宅獨立在上 → 南面開廟埕 → 廣場兼滯洪
   ┌──────────────┐        北30m(商業12F,1F餐廳)→主人流
   │ 社會住宅(上層) │       ┌──────────────┐
   │ 獨立電梯/門禁  │    西 │上:社宅(獨立門禁)│東
   ├──────────────┤  國小 │下:市場/快閃     │20m
   │ 市場/快閃(低層)│ (接送)│  戶外市集廣場   │住宅
   ├──────────────┤       └──廟埕廣場────────┘
   │ 地下停車       │        南15m 廟宇(坐北朝南)+樹群
   └──────────────┘        廣場結合滯洪/透水
```

## 通過關鍵（以考得過為主）

> **概念**「市集疊聚落・廟埕共生」；**垂直分層**（下市集熱鬧、上社宅獨立門禁）是評分核心。**硬要求**：一樓平面＋開挖範圍務必畫。**命名場所**（市集廣場、廟埕廣場）；廟宇涵構回應；廣場兼滯洪呼應申論。失分點：社宅與市場動線不分、社宅沒獨立門禁、廟宇只標位置、忘畫一樓平面/開挖範圍。

> 法規以**全國法規資料庫（law.moj.gov.tw）**最新版本為準；引用以法規名稱為原則。原卷見考選部「考畢試題查詢平台」。
