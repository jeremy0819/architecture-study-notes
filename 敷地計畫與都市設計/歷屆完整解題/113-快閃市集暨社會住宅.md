## 0. 本年關鍵法源（必記）

> **🔑 關鍵法源：《都市計畫公共設施用地多目標使用辦法》＋《住宅法》**
> 基地為**市場（公共設施）用地**，卻要在其上導入**社會住宅與社工站**——這必須靠**《都市計畫公共設施用地多目標使用辦法》**（公設用地得**立體／多目標複合使用**）才合法，是本年的鎖鑰（如同 114 的免計容積）。導入之**社會住宅**依**《住宅法》**（只租不售、保障弱勢比例、包租代管）辦理。
> **答題寫法**：「依《都市計畫公共設施用地多目標使用辦法》，市場用地立體多目標複合社會住宅與社福；社會住宅依《住宅法》只租不售並保障弱勢入住。」

> 另記：水患減洪（呼應申論）→《水利法》出流管制；西側國小→人車安全。


## 4. 申論題擬答（30 分）：水文調查＋減洪方案

> 題目：極端氣候水患的**水文調查**項目；都市排水**未能擴充**下，**都市設計層面**與**敷地計畫層面**分別的減洪方案。
> **用 [04 模板 5：韌性城市（水文變體）](../04-申論版面模板.md#模板-5韌性城市)**。

**破題**：排水管網短期難擴充，須以「**留、滯、滲、用**」於都市設計與敷地兩層面分散滯蓄。

**一、水文調查項目**：降雨強度與頻率、集水區範圍、地表逕流係數、地下水位、**淹水潛勢圖**、排水路與排水分區、土壤入滲率、歷史淹水紀錄。

**二、都市設計層面減洪**：保留滯洪綠地與藍帶、降低不透水率、雨水分區滯蓄、退縮藍綠廊道、低衝擊開發（LID）。

**三、敷地計畫層面減洪**：基地保水（透水鋪面/雨花園/生態滯洪池）、屋頂與中水回收、地面層架高與防水閘、地下室出入口防水高程、基地內逕流分流。

```
〔集水區→基地 逕流分流 示意〕
 集水區→逕流│→[透水鋪面/雨花園]→[生態滯洪池]→排程放流
            │→[屋頂滯洪/雨水回收→中水]
 戶外市集廣場 = 平時市集 / 雨時滯洪(彈性空間)
```

**法源穿插**：「依《水利法》出流管制之精神，基地滯蓄後再放流，不直接排入公共排水溝。」

**小結**：水患減洪＝**把基地變成海綿**；戶外市集廣場兼滯洪，平災兩用。（呼應設計）

## 5. 設計主軸概念

> **主軸：「市集疊聚落・廟埕共生」**——低層市集/快閃/廣場熱鬧對外、上層社宅獨立門禁；南面廟宇開廟埕廣場共享樹蔭。

```
〔垂直分層〕              〔配置關係〕 N↑
 ┌──────────────┐        北30m(商業12F,餐廳)
 │ 社會住宅(上層) │       ┌──────────────┐
 │ 獨立電梯/門禁  │    西 │上:社宅 獨立門禁│東
 ├──────────────┤  國小 │下:市場/快閃    │住宅
 │ 市場/快閃(低層)│ (接送)│  戶外市集廣場  │
 │ 對外熱鬧       │       └──廟埕廣場──────┘
 ├──────────────┤        南15m 廟宇(坐北朝南)+樹群
 │ 地下停車       │        廣場結合滯洪/透水
 └──────────────┘
```

## 6. 圖面回應重點

**全區量體配置（含一樓平面、開挖範圍）**：1F 市場攤位佈局＋快閃彈性區＋戶外市集廣場；南面廟埕廣場；西側國小避車彎；標**開挖範圍**（地下停車）。
**機能關係圖**：低層市場/快閃/廣場（公共、對外）↔ 上層社宅（私密、獨立電梯門禁）；社工站 1F 可及。
**剖立面（各 ≥1）**：垂直分層、社宅獨立動線、廟埕退讓、戶外廣場滯洪/透水。
**透視（≥1）**：廟埕廣場＋市集活動，樹蔭與人群。
