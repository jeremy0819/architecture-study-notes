## 每份解題的固定架構

```
0.5 本年關鍵法源（必記）   ← 鎖鑰
1. 審題：條件清單
2. 量體計算（97–104 以題型重點為主）
3. 課題與對策（Issue→Strategy）
4. 申論題擬答（106 起；97–105 為設計題）
5. 設計主軸概念（一句話＋概念圖）
6. 圖面回應重點（構想/配置/剖面/透視）
7. 總檢核表 → 通過關鍵
```
