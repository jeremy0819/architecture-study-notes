## 每份解題的固定架構

```
0. 本年關鍵法源（必記）   ← 鎖鑰
1. 審題：條件清單
2. 量體計算
3. 課題與對策（Issue→Strategy）
4. 申論題擬答（套版面模板＋法源穿插＋diagram）
5. 設計主軸概念（一句話＋概念圖）
6. 圖面回應重點（配置/機能組織/剖面/透視）
7. 總檢核表
```
