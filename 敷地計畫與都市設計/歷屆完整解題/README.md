## 🔑 每年「關鍵法源」速查表（背這欄）

| 年 | 題型 | 本年關鍵法源（鎖鑰）| 一句話 |
|----|------|------------------|--------|
| 108 | 新住民文化交流中心（住宅區）| **土地使用分區「容許使用」＋建築技術規則集會類防火避難** | 住宅區能不能設此設施＋集會二方向避難 |
| 109 | 都市國小新校園 | **國民中小學設施設備基準＋幼兒園設施標準**；申論考**都更條例×危老條例** | 教室/運動場有基準、幼兒室 1–3F 不設地下 |
| 110 | 地方區政中心（機關）| **公有建築物應取得綠建築標章＋《水利法》出流管制** | 公有建築強制綠建築、濱溪滯洪不直排 |
| 111 | 複合共享辦公＋出租住宅 | **建築技術規則使用類組與防火區劃（住辦分流）＋《住宅法》** | 住辦各自獨立動線/防火區劃 |
| 112 | 公益教育研修中心 | **《文化資產保存法》**（發見疑似遺址停工通報、遺址保存）| 水圳遺址不開挖、地面再現 |
| 113 | 快閃市集＋社會住宅（市場用地）| **《都市計畫公共設施用地多目標使用辦法》＋《住宅法》** | 公設用地立體多目標才能疊社宅 |
| 114 | 停車場複合休閒運動（停車場用地）| **建築技術規則「停車空間免計容積」** | 停車免計容積，才容得下運動量體 |

> 用法：申論／設計說明時，**把該年關鍵法源穿插一句**即有專業感（寫法見 [08 法規金句速記](../08-申論法規金句速記.md)）。法源以**全國法規資料庫**最新版本為準、引用以**名稱**為原則、不硬背條號。

## 每份解題的固定架構

```
0. 本年關鍵法源（必記）   ← 鎖鑰
1. 審題：條件清單
2. 量體計算
3. 課題與對策（Issue→Strategy）
4. 申論題擬答（套版面模板＋法源穿插＋diagram）
5. 設計主軸概念（一句話＋概念圖）
6. 圖面回應重點（配置/機能組織/剖面/透視）
7. 總檢核表
```
