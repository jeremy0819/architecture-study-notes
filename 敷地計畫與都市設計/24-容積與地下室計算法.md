# 24 容積與地下室計算法（九年通用）

> 版本：v1.0｜2026-10-16
> 解決一件事：**地下室到底算不算容積**，以及**題目給的空間面積怎麼變成量體**。
> 本檔所有數字經獨立複算與法規口徑對抗驗證；凡標 ⚠️ 者為本庫待自行核對項。

---

## 1. ★ 五帳歸屬表（地下室的四個身分）

| 項目 | 建築面積 B | 計容積 F | 總樓地板 G | 開挖 D |
|------|:---:|:---:|:---:|:---:|
| 地上各層（一般用途） | ✓（取最大層投影） | ✓ | ✓ | — |
| **地下層・法定停車空間及必要通道** | ✗ | **✗ 得不計入** | ✓ | ✓ |
| 地下層・獎勵增設／自行增設停車 | ✗ | ✗ 得不計入 | ✓ | ✓ |
| 地下層・防空避難（兼作停車時） | ✗ | ✗ | ✓ | ✓ |
| 地下層・機電設備空間 | ✗ | △ 有上限，超過要計 | ✓ | ✓ |
| **地下層・店舖等營業用途** | ✗ | **✓ 要計入** | ✓ | ✓ |

**三條鐵則**

1. **地下層一律不計入建築面積 B**（建蔽率只管地面層的水平覆蓋）。
2. **停車免計容積的法源是《建築技術規則》§162，不是 §59**。
   §59 管「應設幾輛」，§162 管「算不算容積」——這是最常見的誤引。
3. **每輛停車空間換算容積之樓地板面積上限 40 ㎡（不含機械式）**。
   ⚠️ 這是**法定換算上限**，不是「每車必須配 40 ㎡」。
   實際配置含車道約 **35–40 ㎡/輛**，那是**規劃概算**。兩個層級，圖上分開寫。

**最容易爆的錯**

```
❌ ΣFAF ＝ 地上樓地板 ＋ 地下停車 → 與容積上限比
   地下停車不計容積，加進去會「假性超額」，逼你把方案改小。
✅ F ＝ 地上計容積樓地板              ≤ A × 容積率
   D ＝ 地下開挖投影（另立一帳）       ÷ A ＝ 開挖率
   G ＝ 地上 ＋ 地下各層樓地板         （G ≠ F，也 ≠ F＋D）
```

> **D 不是從樓地板加幾趴生出來的。** D 是開挖範圍的**幾何投影**，
> 要從圖上量出並寫算式（例：`D ＝ 44M×38M ＝ 1,672 ㎡`）。
> 外牆厚度、結構柱、擋土壁、車道坡道、採光井都會讓開挖線大於淨樓地板。
> ⚠️ 「開挖率以地下室外牆外緣計」是**自訂口徑**（各地都審量法不一），圖上註明即可。

## 2. 通用五步驟

```
① 定 A    題目給定？圖推？→ 決定要不要寫「約」
② 算上限  B上限 ＝ A×建蔽率　F上限 ＝ A×容積率　法定空地 ≥ A×(1−建蔽率)
③ 算需求  題目各空間「淨面積」加總 → 加公設（口徑擇一，寫明）
④ 配量體  每層樓地板 × 層數 = F；各棟投影相加 = B；檢核 B≤上限、F≤上限
⑤ 地下室  停車核算 → B1 樓地板 → 量出開挖範圍 D → 算 D/A
```

### 2.1 公設口徑：二選一，絕不可混用

| 口徑 | 算法 | 1,900 ㎡ 淨 → |
|---|---|---|
| **(a) 公設占總樓地板 30%** | 淨 ÷ (1−0.30) | **2,715 ㎡** |
| (b) 淨面積加成 30% | 淨 × 1.30 | 2,470 ㎡ |

**差 245 ㎡（F上限的 4.2%）。** 判準：
題目給「**公設比**」→ 通常指占總樓地板，用 **(a) 除法**；
題目給「**室內外加成**」→ 才用 (b) 乘法。
**圖上一定要寫明採哪一種。**

### 2.2 取整規則（全卷統一宣告，否則自己對不起來）

- 面積需求：**無條件進位**（1,712.5 → 1,713）
- 車位數：**無條件進位**（30.4 → 31）
- 百分比：四捨五入到**小數一位**
- 圖推概算的面積**不寫小數**（寫 ≒5,800，不寫 5,806.4）

### 2.3 停車核算：題目沒給車位數時的寫法

> ⚠️ **不要用單一除數**（例如「樓地板÷150」）。150 是技則第一類（商場店舖餐廳）
> 的級距值，拿來除住宅是用錯類組，考官一問「150 哪來的」就答不出來。

考場上照這個方塊寫：

```
〔停車核算・方案〕題目未給車位數與縣市
依《建築技術規則》§59 按用途類組與樓地板面積分別核算，地方自治條例從嚴者從其規定。
  住宅 2,800 ㎡　通則口徑 (2,800−500)÷300 ≒ 8 輛
　　　　　　　　地方加嚴口徑（如臺北市住宅 75 ㎡/輛）2,800÷75 ≒ 38 輛
  辦公 1,760 ㎡　依其所屬類組級距另行核算（餐飲部分另歸類）
  本案取 ○ 輛〔自訂方案──題目未指定縣市，採較嚴口徑並於圖上標明〕
  無障礙車位：依技則 §167-6，≥1 位（超過 50 輛每增 50 輛加 1）
  免計容積檢核：○ 輛 × 40 ㎡/輛 ＝ ○ ㎡（§162 換算上限）
```

> 兩個口徑差 **4.8 倍**——把這個落差寫出來，本身就證明你知道地方得加嚴。
> ⚠️ §59 之級距門檻（300／500 ㎡ 免設、150／300 ㎡ 每輛）本庫未能連線原文核對，
> **考場寫法規名稱與核算邏輯即可，不背級距數字。**

### 2.4 防空避難（會吃掉地下室面積，常被漏算）

依技則 §141：**非供公眾使用 6 層以上、其他供公眾使用 5 層以上**，
應**按建築面積全部**附建防空避難設備。⚠️ 層數門檻本庫標為多來源一致，仍建議自核。

- 實務上**以 B1 停車空間兼作**（平時停車／戰時避難）→ 不另加面積，但圖上要標。
- 依 §162 免計容積，所以 **F 不受影響，D 與 G 受影響**。
- 2026/7/1 起每人面積 0.75 → **1 ㎡**（學校工廠）。

### 3.1 各年需求占 F上限的比例（看得出哪年量大、哪年量小）

| 年 | 需求/F上限 | 設計含意 |

| 107 | 17% | 量極小 → 容積刻意不用滿，換廣場與對三合院的退讓 |

| 108 | 78% | 量緊 → 3 層不夠，必須 4 層 |

### 3.2 停車佔地概算（40 ㎡/輛含車道、3.5 ㎡/機車）

| 年 | 算式 | 面積 | 與開挖的關係 |
|---|---|---|---|
| 107 | 120×40＋25×3.5 | ≒4,888 ㎡ | ÷ 地下層數 ＝ 單層投影；107 的 D＝3,472 → **需 2 層地下** |
| 108 | 12×40＋10×3.5 | 515 ㎡ | B1 一層即可 |
| 110 | 90×40＋50×3.5 | 3,775 ㎡ | B1 一層（基地 31,937） |

> **停車佔地 ÷ 地下層數 ＝ 單層所需投影面積**，再與開挖範圍 D 對照。
> 直接把停車佔地當 D 讀是錯的。

## 4. 三個最容易錯的點

1. **把地下停車加進容積帳** → 假性超額，逼自己把方案改小（這是 111 年實戰圖的真實病例）。
2. **公設口徑 ÷0.7 與 ×1.3 混用** → 整份面積帳差 4%，自己的檢核對不起來。
3. **「題目沒給上限」≠「法規沒管」** → 111 未給高度上限，但技則高度管制、
   面前道路寬、§39-1 冬至日照仍會咬到。高樓層方案要寫出高度並註明已檢討。
