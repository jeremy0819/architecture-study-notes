# 16 圖面法規標註語庫（讓圖面「一看就專業」）

> 適用：專技高考「建築師」──敷地計畫與都市設計（80150）設計題 70 分
> 版本：v1.0｜2026-08-09
> 核心認知：**本科考的是「以圖面反映敷地計畫與都市之關係」**——法規不是寫在申論裡就好，而是要**標在圖上**。
> 搭配：[08 申論法規金句](./08-申論法規金句速記.md)（申論用）｜[references/理論名著精要](../references/理論名著精要.md)（理論句）｜本檔（**圖面用**）

---

## 0. 為什麼圖上要有法規文字

考官看圖的順序是：**先看有沒有（完整性）→ 再看對不對（合法性）→ 最後看好不好（設計）**。
圖上沒有法規標註，第二關就過不去——他無法確認你是「剛好畫成這樣」還是「知道為什麼要這樣」。

> **一句話**：圖上的法規標註，是把你的設計決策從「憑感覺」升級為「有依據」的唯一證據。

### 三個層級（缺一不可）

| 層級 | 位置 | 內容 | 字數 |
|------|------|------|------|
| **L1 設計依據行** | 圖名正下方 | 一行講清本圖依據 | 20–30 字 |
| **L2 引線標註** | 圖上各處 | 指著實物講法規 | **每則 ≤15 字** |
| **L3 法規檢核表** | 圖面角落 | 法定值 vs 本案值 | 一張小表 |

> ⚠️ 手寫在考卷上，**L2 每則超過 15 字就寫不完、也擠不下**。這是實體限制，不是建議。

## 1. 標註公式（背這個就夠）

### 1.1 引線標註三段式

```
〔設計作為〕＋〔數據〕＋〔法源簡稱〕
```

| ❌ 太長／太虛 | ✅ 三段式 |
|-------------|---------|
| 「本區設置透水鋪面以符合綠建築相關規定之基地保水要求」（27 字）| 「透水鋪面｜基地保水（技則）」（12 字）|
| 「此處為法定停車空間」 | 「法停 90 輛｜免計容積（技則）」（13 字）|
| 「退縮做人行道」 | 「退縮 4M 人行帶（都審準則）」（13 字）|
| 「地下室開挖範圍」 | 「開挖率 65%＜70%｜留保水面」（14 字）|

### 1.2 法源在圖上一律用「簡稱」

> 圖上空間有限，**不寫全名、不寫條號**——寫簡稱即可，考官全看得懂。

| 圖上簡稱 | 全名（申論才寫全名）|
|---------|------------------|
| **技則** | 建築技術規則 |
| **技則·綠建築** | 建築技術規則 綠建築基準 |
| **都計法** | 都市計畫法 |
| **都審準則** | （地方）都市設計審議原則／題目給定準則 |
| **水利法·出流** | 水利法 逕流分擔與出流管制 |
| **多目標辦法** | 都市計畫公共設施用地多目標使用辦法 |
| **無障礙規範** | 建築物無障礙設施設計規範 |
| **文資法** | 文化資產保存法 |
| **再生能源條例** | 再生能源發展條例 |

> **鐵則**：圖上**不要寫條號**。條號寫錯是硬傷；寫簡稱不會錯，且完全足夠。
> （條號只在申論、且十成把握時才寫——例如再生能源條例 §12-1。）

## 2. 法規檢核表（最高 CP 值的一招）

> 放在配置圖角落，**一張小表抵一百字說明**。考官掃一眼就知道你全程都在算、都合法。
> 這也是把「量體計算」正式化的作法——不是在旁邊隨手寫式子，而是做成表。

```
┌ 法規檢核表 ────────────────────┐
│ 項目      │ 法定      │ 本案     │ 
│ 基地面積  │ —        │ 3,600 ㎡ │
│ 建蔽率    │ 80%      │ 76% ✓    │
│ 容積率    │ 400%     │ 396% ✓   │
│ 容積樓地板│ 14,400 ㎡ │ 14,256 ㎡✓│
│ 建築高度  │ ≤18M/6F  │ 18M/6F ✓ │
│ 退縮      │ 4M       │ 4M ✓     │
│ 法定停車  │ ○○輛     │ ○○輛 ✓   │
│ 開挖率    │ —        │ 65%      │
│ 綠覆率    │ —        │ 42%      │
└──────────────────────────────┘
```

**四個要點：**
1. **「法定」欄寫題目給的、「本案」欄寫你設計的**——兩欄並列才叫檢核。
2. 每列後面畫 **✓**，代表你有檢查過。
3. 沒有法定值的（開挖率、綠覆率）也要列，寫本案值即可——**表示你主動控制**。
4. 表格畫在配置圖右下或左下角，**約 5×8 cm**，用尺畫線。

> 你 114 年實戰有做量體計算（3600×4＝14400、本案 4000 坪＜4320 坪），評審會看見。
> **升級動作**：把它從「旁邊的算式」變成「這張表」——同樣的內容，專業度差一個檔次。

## 3. 分圖標註語庫（照抄即可）

### 3.1 全區配置圖（法規標註密度最高）

**L1 設計依據行（圖名下）：**
> 「依都計法細部計畫土地使用管制與都市設計準則，建蔽 ○%／容積 ○%，退縮 ○M 留設帶狀開放空間。」

| 綠帶／植栽 | 「複層植栽｜綠化量（技則·綠建築）」 |

### 3.2 一樓平面／開挖範圍圖

| 標在哪 | 標註文字 |

### 3.3 剖面圖（最容易被扣「資訊密度不足」的一張）

> **鐵則：每一層都要有樓高數字**。沒有樓高的剖面等於沒畫。

| 標在哪 | 標註文字 |
|-------|---------|
| 各層樓高 | 「FL＋4.5／3.6／3.6…」（每層都標）|
| 特殊淨高 | 「羽球場淨高 6.1M（大跨距）」 |
| 建築高度 | 「H＝18M ≤ 法定 18M ✓」 |
| 天際線 | 「對鄰棟 3–5F 之高度過渡」 |
| 地下層 | 「B1 停車／B2 貯留池」 |
| 屋頂 | 「屋頂綠化＋光電（再生能源條例）」 |
| 防水高程 | 「防水高程｜地下出入口抬高」 |
| 避難層 | 「避難層／屋頂避難平台（技則·防火避難）」 |

### 3.4 空間組織圖（水平／垂直）

| 標在哪 | 標註文字 |
|-------|---------|
| 垂直分區 | 「低層公共／中層停車／高層專用」 |

| 彈性空間 | 「大跨距｜平災轉換」 |

### 3.5 分析圖（每張一個主題，各一則標註）

| 分析圖 | 標註文字 |
|-------|---------|
| 基地分析 | 「英雄條件：○○」（一句點出主軸）|
| 土地使用 | 「依細部計畫分區管制（都計法）」 |
| 開放空間系統 | 「開放空間連續系統｜公共性」 |
| 人車動線 | 「人車分流｜行人優先」 |
| 防救災 | 「避難動線＋臨時避難場所（災防法）」 |
| 微氣候 | 「夏西南風通風廊道｜遮蔭」 |

### 3.6 透視圖（唯一不用寫法規的圖）

> 透視是**講故事**的圖，不是法規圖。這裡只標**場所名稱與活動**，法規全部不寫。

| 標什麼 | 例 |
|-------|---|
| 場所名 | 「水岸階梯廣場」「樹下客廳」 |
| 活動 | 「假日市集」「親子共讀」 |
| 人物 | 一定要有人（輪椅長者、孩童、推車）|

## 4. 標註密度控制（寫多少才對）

| 圖種 | 法規標註則數 | 說明 |
|------|------------|------|
| 全區配置圖 | **8–12 則** | 密度最高，是主戰場 |
| 一樓平面／開挖 | 3–5 則 | 集中在開挖與防水 |
| 剖面圖 | 5–8 則 | 樓高必標，法規次之 |
| 空間組織圖 | 2–3 則 | 講關係為主 |
| 分析圖 | 每張 1 則 | 一圖一句 |
| 透視圖 | **0 則** | 只寫場所與活動 |

> **總量約 20–30 則**。少於 15 則＝看起來像沒讀過法規；多於 40 則＝圖面被字淹沒、反而扣分。

## 5. 五個常見錯誤（直接扣分）

| ❌ 錯誤 | ✅ 正確 |
|--------|--------|
| 圖上寫條號（「依建築技術規則第 59 條」）| 寫簡稱「（技則）」就好，條號留給申論 |
| 一則標註寫 30 字以上 | 壓到 15 字內；講不完就拆成兩則 |
| 只寫法規名稱、沒寫設計作為 | 「設計作為＋數據＋法源」三段缺一不可 |
| 量體算式隨手寫在空白處 | 做成**法規檢核表**，畫框、對齊 |
| 透視圖也標法規 | 透視只講故事，法規一個字都不要 |

## 6. 2026 趨勢：複合式＋防災題型的標註套組

> 近年題型走向「**多機能複合＋防災韌性**」（113 市場＋社宅、114 停車場＋運動）。
> 這類題必然要回答兩件事：**機能怎麼複合分流**、**災害怎麼應對**。以下是可直接套用的標註組。

### 6.1 複合式機能（分流是關鍵）

| 標註位置 | 文字 |
|---------|------|
| 各機能出入口 | 「○○專用出入口｜獨立門禁」 |
| 垂直分區 | 「公共層／半公共層／私密層」 |
| 共用核 | 「共用梯廳｜分時管理」 |
| 立體複合 | 「公設立體多目標使用（多目標辦法）」 |
| 私密機能 | 「住宅獨立動線（住宅法）」 |

### 6.2 防災韌性（四個層次，各標一則）

| 層次 | 標註文字 |
|------|---------|
| **防洪（水）** | 「地面抬高＋防水閘｜地下貯留」 |
| **避難（人）** | 「臨時避難空間｜雙向逃生（技則）」 |
| **減洪（源頭）** | 「透水＋滯洪｜逕流不直排（水利法·出流）」 |
| **能源（備援）** | 「屋頂光電＋儲能（再生能源條例）」 |

> **一句話收尾（寫在配置圖說明框）**：
> 「本案於分區管制之基本盤上，以透水滯洪、避難動線與立體複合，回應複合機能與防災韌性之雙重要求。」

## 7. 考場執行順序（何時寫這些字）

| 階段 | 動作 |
|------|------|
| 鉛筆稿階段 | **先留白**：標註位置先用淡淡的引線畫好，不寫字 |
| 墨線階段 | 畫完圖形後，**先畫法規檢核表**（有框最安心）|
| 收尾 30 分鐘 | 依本檔語庫**逐則填標註**，從配置圖開始（密度最高）|
| 最後 5 分鐘 | 檢查：每張圖有沒有圖名、比例尺、指北？透視有沒有人？ |

> **時間不夠時的優先序**：法規檢核表 ＞ 配置圖標註 ＞ 剖面樓高 ＞ 其他圖標註 ＞ 透視文字。

---

> 法規以**全國法規資料庫（law.moj.gov.tw）**最新版本為準；圖上以**法規簡稱**標註為原則，不寫條號。
> 地方規定（退縮、面寬、圍牆）以**題目給定準則**或當地都審原則為準，圖上標「（都審準則）」即可。
