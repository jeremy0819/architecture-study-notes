## 0. 這份在做什麼：把「框框」刻進腦子裡

申論題不是「寫滿就好」，而是**圖文並陳、版面有份量**。本份的方法是：

> **先把每個主題的「版面骨架（框框相對位置）」背起來；考場上看到題目關鍵字，就靠反射想起框框，框框裡再填平常練的內容。**

這樣做的三個好處：

1. **不空白**：先畫框（30 秒），框定了，剩下就是往框裡填——**心理上不會卡住**。
2. **有份量**：表格、等角透視、剖面、圖形交錯，**版面一看就「有東西」**（即使沒填滿）。
3. **障眼法**：時間不夠或失常時，**每個框都有三兩行＋一張小圖**，比「一段寫好、其他全空」**得分穩**。

### 三種「填法」符號（本份通用）

| 符號 | 意義 | 提醒 |
|------|------|------|
| 【文字】 | 填**論述文字**（以條列為主，每點一句）| 短句＋關鍵詞，不要長段落 |
| 〔小圖〕 | 填**示意小圖**（diagram／等角透視／剖面／泡泡圖）| 求意不求美，**一定要有標註字** |
| ▣標題▣ | **匡起來的重標題**（製造段落感與份量）| 用雙框線或塗一條底色（highlight）|

### 版面通則（每一頁都適用）

```
┌──────────────────────────────────────┐
│ ▣  主標題（題目關鍵字）  ▣             │ ← 一定匡起來
├──────────────────────────────────────┤
│ 【破題 2–3 行】                         │ ← 點題＋定義
├───────────────────┬──────────────────┤
│ 【文字：分點論述】 │ 〔小圖：示意〕    │ ← 左文右圖
│ 1. …              │   (diagram)       │
│ 2. …              │                   │
│ 3. …              │                   │
├───────────────────┴──────────────────┤
│ 〔表格／剖面／等角透：依主題選〕        │ ← 增加豐富度
├──────────────────────────────────────┤
│ 【結語 1–2 行】（呼應設計題）          │
└──────────────────────────────────────┘
```

> 鐵則：**文字與圖編號對應**（「如圖一」「見剖面紅線」）；全頁 **2–3 主題色**；先畫框、再填字。

## 模板 1：法令規章（比較型）

> **適用**：要你「比較兩部法令／制度的異同」。**比較＝放表格最適當**（表格看起來就是「有點東西」，有沒有填完倒其次）。

### 版面骨架

```
▣  〇〇條例  vs  △△條例  ▣
┌─────────────┐   ┌─────────────┐
│ 〇〇：立法精神│   │ △△：立法精神 │  ← 各一句點出精神
└─────────────┘   └─────────────┘
【1. 重點…】          【1. 重點…】
【2. 重點…】          【2. 重點…】       ← 各條列 3 點
【3. 重點…】          【3. 重點…】
──────────────────────────────────────
┌ 比較表（匡起來）──────────────────────┐
│ 項目      │ 〇〇      │ △△      │     ← 標題列 highlight
│ 1 性質    │          │          │
│ 2 範圍    │          │          │
│ 3 機制    │          │          │
│ 4 誘因    │          │          │
│ 5 規模    │ … (列到 7–11 列都行)│
│ ─────────────────────────────────── │
│ 共同點    │ （整列打通一起寫）        │ ← 最後一列共同點
└──────────────────────────────────────┘
【結語：對敷地計畫／環境的影響 1–2 行】
```

### 速記內容（以 109 都更 vs 危老為例）

| 項目 | 都市更新條例 | 危老重建條例 |
|------|-------------|-------------|
| 性質 | 更新（整建/維護/重建）| 重建為主 |
| 範圍 | 須劃**更新單元** | **個別基地**、免劃更新地區 |
| 機制 | **權利變換**、整體規劃 | 同意後重建、程序簡便 |
| 誘因 | 容積獎勵、稅捐減免 | 容積、稅捐；**時程獎勵 114.5.12 已歸零→規模獎勵** |
| 規模 | 較大、街廓尺度 | 較小、單棟 |
| 共同點 | 加速老舊重建、提升耐震與居住品質、給容積／稅捐誘因 | （同左）|

> 法源以**法規名稱**為準，勿硬背條號（詳見 [§6.7](./03-歷屆考題解析-97至114.md#67-都市更新-vs-危老重建109)）。

## 模板 2：都市設計的角色、功能與影響

> **適用**：問都市設計的**定位／角色／功能／價值／影響**。骨架＝**角色（分支）→ 功能（條列＋等角透）→ 影響（三欄表）**。

### 版面骨架

```
▣  都市設計的 角色・功能・影響  ▣
[角色]─┬─ 上承：都計法 §15 主要計畫（指導）
       ├─ 中接：§22 細部計畫（土管平台）        〔等角透小圖：
       └─ 下啟：建築／都審（落實人本尺度）        量體群之間的
──────────────────────────────────────────      開放空間關係〕
[功能]【1. 建立整體空間架構】
      【2. 改善都市環境景觀】
      【3. 創造城鄉新風貌】                     〔小剖面：街道斷面
      【4. 提升生活環境品質】                     退縮/騎樓/人行〕
──────────────────────────────────────────
┌ 影響（三欄表，標題列 highlight）──────────┐
│ 實質環境   │ 社會經濟   │ 環境永續    │
│ 紋理/天際線│ 公共性/活絡│ 微氣候/綠網 │
└────────────────────────────────────────┘
【結語：設計都市而非設計建築物（Lynch）1–2 行】
```

### 速記內容

- **角色（上承下啟）**：都市設計是法定計畫體系「往下的實質轉譯界面」——上承 §15 指導、中接 §22 土管、下啟建築與都審。
- **功能（都審宗旨四句）**：建立整體空間架構、改善都市環境景觀、創造城鄉新風貌、提升生活環境品質。
- **核心理念**：1970 後「**設計都市，而不是設計建築物**」，拉開開放空間的**公共性**（108 申論核心）。
- 法定架構詳見 [都審 §2](./02-都審原則與教學檢核.md#2-法定架構與位階)。

## 模板 3：都市設計的流程

> **適用**：問**作業流程／程序／步驟**，或 108 的 programming 觀。**既然是流程，就是一堆箭頭**；都審流程**死背進去就對了（沒有很多）**。

### 版面骨架

```
▣  都市設計（都審）作業流程  ▣
┌ 基地調查 ┐
     │↓
┌ 課題分析 ┐ ───────〔小圖：基地 diagram
     │↓                   （氣泡＋箭頭）〕
┌ 目標設定 ┐
     │↓
┃ 設計準則 ┃ ←（highlight＝核心步驟）
     │↓
┌ 方案設計 ┐
     │↓
┌ 都審／公展 ┐ ── 死背：申請→幹事會初審→委員會大會
     │↓                  審議→修正→核定
┌ 建照→施工→管理維護 ┐
──────────────────────────────────────
【programming 觀（Lynch）】空間計畫**不是既定條件**，
 應放回基地檢討、修正、再定義（108 申論核心）
```

### 速記內容

- **設計流程**：基地調查 → 課題分析 → 目標設定 → **設計準則** → 方案設計 → 都審／公展 → 建照／施工／維管。
- **都審程序（死背）**：申請 →（都市設計）**幹事會初審** →（都市設計審議）**委員會大會審議** → 修正 → 核定。
- **programming 觀（108）**：不應把業主預擬的空間計畫視為既定條件，要**放回基地環境檢討、修正、更細緻定義**。
- **立體化流程（114）**：流程的每一步都可由平面延伸到**立體多層次**（見 [114 解題 §4](./06-114年完整解題.md#4-申論題30-分完整擬答圖示)）。

## 模板 4：基地分析

> **適用**：110／112 直接考「分析項目、方法、資料來源」。骨架＝**項目（分支引線）→ 中央氣泡疊圖 → 量體方案小圖**；**剖面波浪線**表現水文。

### 版面骨架

```
▣  基地分析：項目・方法・來源  ▣
[自然]──→╲
[人為]──→ 〔中央氣泡：三橢圓疊圖
[法規]──→╱   ＝自然/人為/法規 交疊〕
[非量化]─→     + 〔波浪線剖面＝水文/地形〕
                 + 虛線＝環境敏感區/歷史緩衝
──────────────────────────────────────────
【量化項目】氣候・地質土壤・水文・植生・動物・
           土地使用・交通・噪音・景觀・污染・適宜性
【非量化(112)】社會・歷史・文化・記憶・場所感
【資料來源】氣象署/地調所/地政(地籍地形)/都發局
           (都計細計)/建管(建築線)/文化局(文資)/
           交通單位/現勘與訪談
──────────────────────────────────────────
〔量體方案小圖：3–6 個旋轉方框＝不同配置方案比較〕
 → 說明「分析如何引導出設計方向」（110 要求）
```

### 速記內容

- **自然**：氣候（日照/風/雨/溫濕）、地形坡度、地質土壤、水文、植生、生態。
- **人為**：土地使用分區、道路交通、大眾運輸、鄰棟天際線、公共設施、噪音污染、基礎設施。
- **法規**：都計層級、建蔽容積、退縮、都市設計準則。
- **非量化（112）**：社會、歷史、文化、記憶、場所感；管道＝口述歷史、老地圖、田野訪談、社區工作坊、文化局文資資料庫。
- 詳見 [§6.6](./03-歷屆考題解析-97至114.md#66-基地分析作業項目110112)、[雙軌分析](./02-都審原則與教學檢核.md#3-雙軌分析紋理量化與涵構質化)。

## 模板 5：韌性城市

> **適用**：111／113／114 的韌性城市、水患減洪、街道斷面。骨架＝**定義框 → 要素（條列＋量體圖）→ 立體化六面向 → 街道斷面剖面**。

### 版面骨架

```
▣  韌性城市 ＋ 立體化作為  ▣
┌ 定義 ┐ 抵抗(robust)/回復(recovery)/
        調適(adaptation)/再組織
──────────────────────────────────────────
【關鍵要素】
 【藍綠基盤】【海綿城市】【多元備援】          〔量體小圖：旋轉方框
 【分散式系統】【彈性空間】【社區自主防災】       ＝立體分區/退台〕
──────────────────────────────────────────
【立體化六面向(114)】
 防洪｜綠化｜水資源｜替代能源｜避難｜空間彈性
──────────────────────────────────────────
〔街道斷面剖面(111 雙向六線道)〕
 人行|綠帶|自行車|━車道×6━|綠帶|人行
 + 透水鋪面/行道樹遮蔭/側溝滯洪
 ▽▽▽（三拱橋/排水渠示意，水位低於路面）
```

### 速記內容

- **定義**：城市面對衝擊（洪水/地震/熱浪/疫情）的抵抗、回復、調適、再組織能力。
- **都市設計關鍵要素**：藍綠基盤、海綿城市（透水/滯洪/入滲/再利用）、多元備援、分散式系統、彈性空間、社區自主防災。
- **立體化六面向（114）**：
  - 防洪＝地面架高/防水閘、地下貯留池、屋頂滯洪；
  - 綠化＝屋頂綠化（≥1/2）、立面垂直綠化、退台複層植栽；
  - 水資源＝屋頂雨水回收→中水；
  - 替代能源＝屋頂/立面光電＋EV（再生能源條例 §12-1）；
  - 避難＝垂直避難層、屋頂避難平台、雙逃生梯；
  - 空間彈性＝大跨距無柱樓板平災轉換。
- **水文調查（113）**：降雨強度頻率、集水區、逕流係數、地下水位、淹水潛勢、排水分區、入滲率、歷史淹水。
- 詳見 [§6.1](./03-歷屆考題解析-97至114.md#61-韌性城市111113114-高頻)、[§6.2](./03-歷屆考題解析-97至114.md#62-水文調查與減洪113)。

## 速用：考場 5 步驟

1. **看關鍵字 → 選模板**（法令/角色/流程/基地/韌性）。
2. **先畫框**（▣標題▣＋文字框＋圖框，30 秒）——心理上就不會空白。
3. **填重標題**（把題目關鍵字寫進 ▣ 框）。
4. **左文右圖交錯填**（每框 2–3 句＋一張帶標註的小圖）。
5. **結語呼應設計題**（一句話把申論觀念接到本卷的設計策略）。

> **障眼法心法**：寧可**每個框都有東西**，不要**一框寫滿、其他全空**。表格／剖面／等角透／圖形交錯，版面自然「有份量」。各模板都可**依自己想法調整**——以上只是慣用版。
