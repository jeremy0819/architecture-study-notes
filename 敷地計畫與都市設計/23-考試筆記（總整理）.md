# 0. 四小時作戰時間軸

> **核心判斷：這科考的是「以圖說表達敷地計畫與都市之關係」。**
> 圖面是主體，文字是圖的標籤——不是圖的替代品。

| 時間 | 做什麼 | 產出 | 死線 |
|------|-------|------|------|
| **0–10 分** | 讀題兩遍。**把圖說清單抄在圖紙角落**，每完成一項打勾 | 圖說清單 ✓ 格 | 一定要做——114 年缺透視就是漏了這步 |
| **10–25 分** | **面積五帳＋證據等級**。基地邊界來源？給定還是圖推？ | 角落算式草稿 | 沒給上限就不要發明 |
| **25–40 分** | 抓**英雄條件**（基地最強的那個外部資源／限制）→ 定主軸與標題 | 主標＋副標一行 | 主軸要能用平剖驗證 |
| **40–55 分** | 打版面格線（三欄）、放圖框位置 | 空版面 | 版面先定，內容後填 |
| **55–130 分** | **畫全區配置圖**（含開挖範圍）＋引線標註 | 中欄上半 | 最大的一張，時間最多 |
| **130–165 分** | **兩向剖立面**（頂部段名／右側樓高／關鍵淨高） | 中欄下半 | 剖面是第二大分數來源 |
| **165–185 分** | **透視**（一定要有人物）＋說故事三行 | 中欄底 | 缺透視＝未完整回應題目 |
| **185–215 分** | **左欄四格分析**（每格 ≤100 字） | 左欄 | 文字最少的一區 |
| **215–225 分** | **申論**（若未先寫）／補完右欄檢核表 | 右欄 | — |
| **225–240 分** | **交卷前檢核**（第 7 章） | 打勾 | 15 分鐘不能省 |

> **申論何時寫？** 兩種都可以，但**選一種並固定**：
> ① 先寫申論（趁腦子清楚，45 分鐘）→ 剩 3 小時畫圖；
> ② 先畫圖到剖面完成，再回頭寫申論（避免圖畫不完）。
> **本庫建議 ②**——圖畫不完的風險遠高於申論寫不完。

# 1. 法系架構（可默寫）

## 1.1 六層總表

| 層 | 名稱 | 法源 | 定什麼 | 對敷地計畫的意義 |
|----|------|------|--------|----------------|
| 0 | 國土計畫 | 國土計畫法 | 國土功能分區 | 指導都計 |
| **1** | **主要計畫** | 都計法 **§15（十款）** | 範圍、人口推計、土地使用**配置**、主要道路、上下水道、**全區性**公設、實施進度 | 定「這塊地屬什麼分區、周邊有什麼系統」 |
| **2** | **細部計畫** | 都計法 **§22（七款）** | 計畫範圍、居住密度、**土地使用分區管制**、事業財務、道路系統、**地區性**公設 | **管制的法定平台** |
| **3** | 土地使用分區管制 | 都計法**第三章**＋地方土管要點｜**§32** 分區得再細分、分級管制 | 允許使用、**建蔽、容積、退縮、高度、停車** | **量體計算的直接依據** |
| **4** | 都市設計準則／都審 | 細部計畫之**都市設計基準**＋地方都審自治法規 | 量體造型、開放空間、人行介面、綠化、防災 | 管「形態與公共性」 |
| **5** | 建築管理 | 建築法 → **建築技術規則** → 建照 | 基地配置、法定空地、防火避難、停車、綠建築基準 | **技術底線** |
| **6** | 敷地計畫 | （非法定名詞） | 把 1–5 整合落在一塊基地上 | **就是你考卷上那張配置圖** |

> **一句話**：主要計畫定**位置**、細部計畫定**數字**、都市設計準則定**形態**、
> 建築技術規則定**底線**、敷地計畫把它們**畫成一張圖**。

## 1.2 八個連接動詞（層級人人會背，動詞才看出懂不懂）

| 關係 | 動詞 | 考卷寫法 |
|------|------|---------|
| 國土 → 都計 | **指導** | 上受國土計畫之指導 |
| 主要 → 細部 | **指導** | 依主要計畫之指導擬定細部計畫 |
| 細部 ← 主要 | **不得牴觸** | 細部計畫不得牴觸主要計畫 |
| 細部 → 管制 | **載明** | 細部計畫載明土地使用分區管制 |
| 管制 → 數字 | **訂定** | 依分區管制訂定建蔽率、容積率與退縮 |
| 準則 → 管制 | **補充** | 都市設計準則補充分區管制之形態管制 |
| 都審 → 個案 | **審查** | 經都市設計審議審查通過 |
| 建照 → 落地 | **據以** | 據以請領建造執照 |

## 1.3 ★ 都審的雙依據（最容易被鑑別出程度的地方）

| | 是什麼 | 例 |
|---|-------|---|
| **實體依據**（審什麼標準） | **細部計畫**之土管要點／都市設計基準 | 退縮 4M、面寬 70% |
| **程序依據**（怎麼審） | 地方**都市設計審議自治法規** | 幹事會 → 委員會 → 核定 |

> 兩者**不可混為一談**。考場安全寫法：
> 「依都市計畫書、土地使用分區管制要點、都市設計準則及地方相關規範辦理」。
> **不要下「都計法無明文授權都審」這種法律結論。**

## 1.4 ★ 都市設計「七款應表明事項」（都市計畫定期通盤檢討實施辦法）

> 這七款就是**都審在審什麼**的官方清單，也是設計題要回應的項目。**建議背下來。**

| # | 應表明事項 | 圖上對應 |
|---|-----------|---------|
| 1 | 公共開放空間系統配置及其**綠化、保水** | 開放空間系統、透水鋪面 |
| 2 | **人行空間、步道或自行車道**系統動線配置 | 人行動線 |
| 3 | **交通運輸系統、汽機車與自行車停車空間及出入動線** | 車道／機車出入口分設 |
| 4 | **建築基地細分規模及「地下室開挖」之限制** | **開挖範圍圖** |
| 5 | **建築量體配置、高度、造型、色彩及風格** | 配置＋剖面天際線 |
| 6 | **景觀計畫** | 景觀／植栽 |
| 7 | 其他應加表明事項 | — |

> 💡 **這就是近年題目都要標開挖率／開挖範圍的原因**——第 4 款把「地下室開挖之限制」
> 明列為都市設計應表明事項。112、113、114 連續要求標開挖範圍，不是巧合。
> ⚠️ 但這是**通盤檢討辦法的都市設計應表明事項，不是都計法 §22 條文本身**；
> 實際開挖上限仍依題目／土管／都審，**題目沒給就不要發明百分比**。

## 1.5 三個位階觀念（寫對就贏八成考生）

1. **§15 是「指導」、§22 是「管制平台」、§32 是分區分級管制之依據**
   ——⚠️ 勿把 §32 說成主要計畫內容（§32 在第三章 土地使用分區管制）。
2. **退縮數字與土管要點是「地方／個案」規定，不是全國法律**
   ——考卷寫「依細部計畫土管要點／依題目給定準則」。
3. **「敷地計畫」不是法定名詞**（學科用語，源自日文「敷地」＝基地）
   ——法規對應概念是「**建築基地／法定空地**」（建築法 §11）。
   ⚠️ **不要寫「依敷地計畫法規定……」——沒有這種法。**

## 1.6 三個容易引錯的條號

| 常見誤寫 | 正確 |
|---------|------|
| 回饋捐贈＝ §27-2 | ❌ 回饋是 **§27-1** |
| §27-2 是什麼 | **重大投資開發案平行作業／聯席審議** |
| 停車免計容積＝技則 §59 | ❌ 是 **§162-1-3**（§59 是停車位數量核算） |
| 日照規定 | 技則 **§39-1** |
| 公設多目標使用之授權 | 都計法 **§30 第 2 項** |

# 2. 五帳與必算數字

## 2.1 ★ 面積五帳（不可只算三帳）

> 📐 **地下室到底算不算容積、停車怎麼核算、公設口徑怎麼選** → [24 容積與地下室計算法](./24-容積與地下室計算法.md)（含五帳歸屬表與九年速查）

```
A ＝ 基地面積
B ＝ 建築面積（最大水平投影）
G ＝ 實際總樓地板面積
F ＝ 計容積樓地板面積
D ＝ 地下開挖面積

建蔽率 ＝ B / A      容積率 ＝ F / A      開挖率 ＝ D / A
```

- ❌ **不能把「需求淨面積」直接當成 F**。
- ❌ **不能把公設率加上去之後、又宣稱全部免計**。
- 機房、梯間、停車是否免計，須對應**法定項目、面積上限與實際用途**。

## 2.2 必背換算與係數

| 項目 | 數值 | 出處 |
|------|------|------|
| **1 坪** | **400/121 ＝ 3.3058 ㎡** | 以 3.3 概算須標「約」 |
| **雨水貯集** | 基地面積 **× 0.045 m³/㎡** | 技則 §4-3 |
| **每車概估** | 約 40 ㎡／車 | ⚠️ 這是**容積換算上限相關數字**，**不是每車法定必須面積**；車道、柱位、坡道、機車仍須各自驗證 |
| **出流管制門檻** | 一般開發 **1 公頃**／都計區內新建 **0.2 公頃** | ⚠️ **114 年 9 月新制（含一年緩衝）**，答舊題不可倒推 |
| **屋頂光電** | 建築面積 **≥1,000 ㎡**，每 **20 ㎡ 設 1 瓩** | 建築物設置太陽光電發電設備標準（115.8.1 施行）⚠️ 是**建築面積**不是樓地板 |
| **防空避難** | 學校工廠每人 0.75 → **1 ㎡** | 技則修正，**115.7.1 施行** |
| **多目標容積** | 一般 **≤ 總容積樓地板 1/3** | 社福用途經特定審議得放寬 1/2，**不能移用到其他用途** |
| **無障礙坡道** | 縱坡 **≤1/12** | 無障礙設施設計規範 |
| **走廊淨寬** | 單邊 ≥2.5 M／中央 ≥3 M；樓梯 ≥1.4 M | 學校類 |

## 2.3 ★ 數據證據四分級（每個數字都要說得出等級）

| 級別 | 定義 | 圖上怎麼寫 |
|------|------|-----------|
| **① 題目給定** | 正文直接寫出 | 直接標，不加修飾 |
| **② 圖推概算** | 正文沒給，由附圖幾何判讀 | **加「約／概算」＋寫算式** |
| **③ 自訂方案** | 題目未指定、由你設定 | **加「方案／自訂」** |
| **④ 題目未指定** | 題目根本沒要求 | **明寫「未指定」，不捏造** |

**三種安全句型（寫上去不扣分而且加分）：**

```
〔圖推〕　基地約 2,600 ㎡（50×59−25×14，依題圖概算）
〔自訂〕　1房 40 ㎡／2房 60 ㎡（房型面積題目未指定，自訂方案）
〔未指定〕汽車總車位：題目未指定；本案僅證明機車位＝汽車位、坡道與排隊不衝突
```

> ⚠️ **最常見的失分**：把 ② 寫成 ①（冒稱官方精確面積）、
> 把 ③ 寫成 ①（自訂值當題目硬條件）、把 ④ 憑空補一個數字。

## 2.4 讀完題目的六步驟（先確認證據等級，再設計）

1. **辨明土地邊界與面積來源**（題目給定？圖推？）
2. 核對題目必要空間、戶數與**圖說清單**
3. 建立 **A／B／G／F／D 五帳**
4. 檢查**高度、停車、用途比例與開挖**——**沒給上限就不要發明**
5. 選主軸並畫平面與剖面
6. 逐條查明**每一項圖說是否有圖面證據**

> **考場判準**：不是「我有想到」就算解題，而是每一個題目限定詞，
> 都必須在配置、組織圖、表格或剖面上找到**一個考官可以直接打勾的證據**。

# 3. 圖面方法

## 3.1 固定版面（九年一致，直接抄）

```
A1 橫式（或題目規定尺寸）
┌── 左 22% ──────┬──── 中 52% ────────────┬── 右 26% ──────┐
│ ① 基地硬條件    │  ▮全區配置圖 N S=1/○○○ │ 【大標題】      │
│   與環境        │   （最大的一張）         │  副標一行       │
│ ② 英雄條件・    │   樓層機能標在量體上     │                │
│   課題與對策    │   引線標註環繞           │ ▮申論題        │
│ ③ 空間需求・    ├────────────────────────┤  條列＋小圖     │
│   量體與開放空間│  ▮A-A' 剖立面           │ ▮圖說要求打勾   │
│ ④ 人車動線・    │  ▮B-B' 剖立面           │ ▮數值證據分級   │
│   防災與管理    │   頂部段名＋右側樓高     │ ▮法規檢核       │
│                │  ▮局部透視（要有人物）   │ ▮交卷前檢核     │
└────────────────┴────────────────────────┴────────────────┘
```

> 九張範例圖見 [`圖說/README.md`](../圖說/README.md)｜合訂 PDF 可直接列印臨摹。

## 3.2 ★ 字數預算表（總手寫字數 900–1,300 字）

| 區域 | 字數上限 | 檢查方式 |
|------|---------|---------|
| 左欄四格分析 | **每格 ≤100 字**（3 點×每點 2 行） | 超過 3 點就刪 |
| 配置圖引線標註 | **每則 ≤15 字**，共 8–12 則 | 數超過 15 字的有幾則 |
| 剖面標註 | **每則 ≤15 字**，共 5–8 則＋每層樓高數字 | 同上 |
| 分析圖 | **每張 1 則標註** | 一圖一句 |
| 透視圖 | **每張 2–3 行說明** | 場所＋角色＋誰＋做什麼 |
| 申論區 | **400–600 字**＋3–5 張小圖 | 唯一可以寫成段的地方 |

### ★★ 三行原則（最重要的一條規矩）

> **除申論區外，圖面上任何一處文字不得超過 3 行。**
> 超過 3 行＝這段話**該畫成圖**，不該寫成字。

## 3.3 七種「文字 → 圖」轉換

| # | 文字長這樣 | 改成 |
|---|-----------|------|
| 1 | 層級／從屬關係 | **泡泡圖**（大圈套小圈＋連線） |
| 2 | 動線描述 | **箭頭圖＋圖例**（人行紅／車行藍／自行車綠） |
| 3 | 垂直機能 | **寫在量體方塊裡**（RF 屋頂花園／6F 桌球館／…）——省一張平面圖 |
| 4 | 因果／效益 | **「名詞－效益」標籤**，5–15 字 |
| 5 | 計算／檢核 | **算式＋「… ok!」** |
| 6 | 比較 | **表格** |
| 7 | 程序／多點論述 | **編號條列 ①②③ ＋圖上標同樣編號** |

**引線標註公式：`名詞－效益`**
- `退縮綠帶－隔噪音・廢氣`
- `街道家具－提供停留休息`
- `汽機車動線分流－提高安全性`

## 3.4 五色系統（只用五色）

| 色 | 用途 |
|----|------|
| 綠 | 植栽、綠地 |
| 藍 | 水體；**所有引線標註文字** |
| 黃／橘 | 開放空間、廣場、人行動線 |
| 紅 | 重點、**開挖範圍**、[分類標題] |
| 灰 | 周邊既有建物（襯底，不搶戲） |

## 3.5 剖面的資訊密度（三件事缺一不可）

1. **頂部**標出剖到的每一段名稱與寬度（`西社區巷道 15M｜行政中心 75M｜…`）
2. **右側**每一層標樓高數字（`3F`／`1F 4.5M`）
3. **關鍵淨高**明確標出（羽球場 6.1M、大廳挑高 4.5M）

**加分：紅色 [分類] 標註貼在剖面周圍（5–6 組）**
```
[室內環境] 綠建材・低VOC材料      [基地保水] 透水鋪面・滲透側溝
[日常節能] 遮陽・LED・高效設備    [水資源]   雨水回收再利用
[廢棄物減量] 基地土方回填         [複層植栽] 增加生物多樣性
```

## 3.6 透視說故事公式

> **`場所名稱 ＋ 在設計中的角色 ＋ 誰在這裡 ＋ 做什麼`**

範例：
> 「**大樹木平台**錨定了主廣場，為本設計的**精神中心**，逛街時可在此休憩、玩樂，
> 並歡迎**學生、民眾**的到來。」

**透視一定要有人物。** 不是畫得美，是**文字把場所的意義講出來**。

# 4. 申論方法

## 4.1 ★ 反射起手骨架（固定 45 字，每年照抄）

> 「**本案依都市計畫法主要計畫（§15）之指導、細部計畫（§22）之土地使用分區管制，
> 並依都市設計準則管制量體與開放空間，……〔接本年議題〕。**」

> 前半 45 字每年不變（反射默寫）；**破折號後那一句「轉折」才是當年議題**。

**萬用收尾式：**
> 「全案於《建築技術規則》（停車、無障礙、防火避難、綠建築基準）之基本盤上，
> 導入屋頂光電與出流管制之減洪作為，落實安全、永續且具公共性之實質環境。」

> 起手＋收尾**一頭一尾各放一次**，中間論點各補**一句**對應法源即可。
> 一份申論穿插 **3–5 句法源**就很有份量；多了像背法條，擠掉你的論述。

## 4.2 五種版面模板（看題型選一個）

| 模板 | 用在什麼題 | 骨架 |
|------|-----------|------|
| **1 比較型** | 法令規章比較（109 都更 vs 危老） | 定義 → **比較表**（範圍／程序／誘因／限制）→ 角色與限制 → 小結 |
| **2 角色功能影響** | 都市設計的角色（107 廣場、106 記憶保存） | 定義與種類 → 角色 → 影響 → **配置＋剖面示意圖** → 小結 |
| **3 流程型** | 都市設計的流程、審議程序 | 階段條列 ①②③ → 每階段產出 → **箭頭流程圖** → 小結 |
| **4 基地分析** | 非量化基地分析（112）、分析作業項目（110） | 分類表（自然／人為／法規／非量化）→ 資料來源 → **疊圖→設計** → 小結 |
| **5 韌性／環境** | 韌性城市（114）、微氣候（106）、減洪（113）、縫合（108） | 成因 → 影響 → **分層對策**（都計／都設／敷地）→ 本案示範 → 小結 |

**每個模板共通：段段有小結、最後有總結。** 這一項 114 年你已經做到，保持住。

## 4.3 法規金句（一句帶過，不堆砌）

> 寫法公式：**「依《○○法》（之精神），本案……（你的設計作為）」**

| 主題 | 引這部法 | 即時可寫句 |
|------|---------|-----------|
| 上位指導 | 都市計畫法（主要計畫） | 依主要計畫之指導，落實土地使用配置與公共設施系統 |
| 管制平台 | 都市計畫法（細部計畫） | 依細部計畫之土地使用分區管制，核算量體與留設 |
| 都審 | 都計法＋地方都審原則 | 依都市設計審議之精神——建立整體空間架構、改善環境景觀、提升生活品質 |
| 停車 | 建築技術規則 | 法定停車空間、獎勵增設及自行增設停車空間**得不計入**容積總樓地板面積 |
| 無障礙 | 建築物無障礙設施設計規範 | 設連續無障礙通路、坡道（縱坡 ≤1/12）與無障礙電梯 |
| 防空避難 | 建築技術規則 | 達一定規模之建築應設防空避難設備（多設於地下層） |
| 保水綠化 | 建築技術規則綠建築基準 | 依基地保水、綠化量指標，採透水鋪面與複層植栽 |
| 屋頂光電 | 再生能源發展條例 | 於屋頂設置太陽光電發電設備，導入低碳能源 |
| 減洪 | 水利法（出流管制） | 基地內設滯洪／貯留與透水設施，不直接排入公共排水溝 |
| 文資 | 文化資產保存法 | 留設保存緩衝與視覺廊道，維繫紋理與場所精神 |
| 都更／危老 | 都市更新條例／危老條例 | 以更新單元與權利變換整體規劃／就個別基地加速重建 |
| 社宅 | 住宅法 | 導入只租不售之社會住宅並設獨立出入口與門禁管理 |
| 多目標 | 公共設施用地多目標使用辦法 | 將停車與運動／綠地立體複合使用 |
| 防救災 | 災害防救法 | 地面層留設地震臨時避難場所，串聯防救災動線 |

## 4.4 ★ 六個法規地雷（務必避開）

| 常見誤寫 | 正確 |
|---------|------|
| 屋頂光電「佔屋頂 20%」 | **無此法定比例**。依設置標準：建築面積 ≥1,000 ㎡、每 20 ㎡ 設 1 瓩 |
| 出流管制＝都計法 §27-2 | ❌ 出流管制引 **《水利法》**；§27-2 是重大投資開發平行作業 |
| 回饋捐贈＝ §27-2 | ❌ 回饋是 **§27-1** |
| 文資保存＝「九大指標」 | ❌ 九大指標是**綠建築 EEWH**；文資引**文化資產保存法** |
| SWOT ＝都計法 §15 法定款次 | ❌ 那是**分析方法**，非法條 |
| 退縮 4M／面寬 70% 當全國法律 | ❌ 多為**地方都審／題目給定**；寫「依題目給定準則」 |

- ⚠️ **最易錯**：F＝10,400 ㎡ **只餘 100 ㎡、不到 1% 彈性**——要寫敏感度
  （非住宅增至 2,000 ㎡ 即達 11,000 超限）；
  **地下停車不可略去**，須依用途與面積核算；

  社宅走**公共使用／社會福利設施**途徑（非附表「住宅」項），**仍須個案認定核准**，

  🔴 **0.2 公頃出流管制門檻是 114 年新制，不能當 113 年當時法規**

### 114 停車場立體多目標使用複合休閒運動設施
- **題眼**：立體化｜韌性｜多目標使用｜控高
- **英雄條件**：**西側 33M 園道與 14M 生態排水渠**
- **關鍵作為**：停車立體收納（取最大值 7–8 成）／省下的地面換成廣場、市集、運動——**要在圖上交代**／小橋石階跨渠與園道「**部分連接**」／量體退向東、中，西側整條留帶狀開放空間
- ⚠️ **最易錯**：🔴 **「停車免計容積 → 容積全給運動」是錯的**——多目標容積一般
  **≤ 總容積 1/3 ＝ 4,800 ㎡**；
  🔴 **高度條件方向相反**：附表准許條件是高度「**超過**」6F/18M 之例外，
  題目要求原則「**不超過**」，**兩者不是同一個上限**——應依考題規劃並註明審議前提；
  A：正文約 3,600／圖示 50×54+32×28＝**3,596 ㎡**，**不得混用分母**；
  **西側與南側「均」退縮 4M**（不是只有西南角）；
  **西側與園道之間有 12M 道路**，要畫穿越，**不是連成自家綠地**；
  **六層 ≠ 六個 3M 樓層**（羽球淨高 6.1M＋結構設備）；
  ⚠️ **停車場兼滯洪不得使有人／有車區域臨時受淹**

## 5.3 出題趨勢（2026 應試提醒）

| 趨勢 | 證據 | 準備方向 |
|------|------|---------|
| **複合式發展** | 112 研修中心｜113 市集＋社宅｜114 停車＋運動 | 多目標使用辦法、垂直分層、公私動線分離 |
| **防災／韌性** | 113 減洪｜114 立體韌性｜通盤檢討辦法 114.7.22 納入防災 | 三層次防災（防空／地震／防洪）、滯蓄設施要畫集水蓄水溢流維護 |
| **開挖範圍必標** | 112、113、114 連續要求 | 紅虛線框＋「開挖範圍」紅字＋ D 與 D/A 算式 |
| **一樓平面** | 113 明文要求 | 平面要畫得出攤位模矩、卸貨、門廳 |
| **剛生效新制** | 光電標準 115.8.1｜防空避難 115.7.1 | 命題誘因高，且都能直接落在圖上 |

# 6. 常錯清單（本庫自我揭露）

## 6.1 方法論層級的更正

| 原本的說法 | 問題 | 改為 |
|-----------|------|------|
| 「一塊基地只有**一個**真正的問題」 | 八年題目均同時含數量、環境、活動、動線、圖說要求 | 「**優先組織設計的主軸**」（不是唯一） |
| 「80% 分數來自 20% 的決策」 | **無官方評分證據** | 刪除 |
| 「缺 1 張＝硬扣」「沒畫等於放棄」 | 官方未公布扣分標準 | 一律改為「**未完整回應題目要求**」 |
| 算式末寫「… ok!」 | 可作自我檢核 | 保留為檢核習慣，**不宣稱合規** |
| 「直接照抄即可及格」 | 無依據 | 刪除 |

## 6.2 主軸判斷四準則（取代「唯一問題」）

① 是否符合題旨　② 是否能處理高風險限制　③ 是否能連接多項機能　④ **是否能用平面與剖面驗證**

## 6.3 跨年通則

- **基地外的公園、河渠、防汛道、廟宇庭園，不得計入基地面積或法定空地**；
  借景 ≠ 擁有用地控制權，**連通需要實際跨路路徑**。
- **1 坪＝400/121 ≈ 3.3058 ㎡**；用 3.3 換算要**明示為概算**。
- ⚠️ **40 ㎡／車是容積換算上限相關數字，不是每車法定必須配置面積**。
- 透水鋪面、生態水池、綠屋頂可保留，但須畫**集水、蓄水、溢流與維護路徑**；
  **生態池水面面積不能當滯洪有效容積**。

## 6.4 跨年水文法規的版本分界

| 項目 | 內容 |
|------|------|
| **出流管制門檻** | **114 年 9 月新制**：一般開發 1 公頃／都計區內新建 0.2 公頃，有一年緩衝期 |
| ⚠️ 版本紀律 | **不能把 114 年新制當作 113 年當時門檻** |
| 制度不可混用 | **出流管制／基地保水／雨水回收／多目標辦法 §2-1 逕流要求**各有法源，須**獨立檢核** |
| 滯洪驗證 | 須用設計水位差、出流設施與事件歷線驗證 |

## 6.5 應撤回的宣稱

❌ 未證實的得分百分比　❌ 唯一正軸　❌ 直接照抄即可及格
❌ 把 2,000 ㎡ 當 107 量級　❌ 把 2,950 ㎡ 當 111 基地　❌ 把停車免計推成 114 無比例限制

# 8. 一句話

> 及格考生九年下來，**不是畫得比較快，是決策比較少**——
> 版面、模組、句型都預先決定好，考場上只剩填內容。
>
> 而之所以「專業」，是因為**知道哪些話不必用寫的**：
> 圖面上的文字只有三種身分——**標籤（指認）、算式（證明）、故事（透視說明）**，
> 其餘一律畫成圖。
