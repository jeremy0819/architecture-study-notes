## 🧭 三個核心認知

1. **圖說項目缺一項 = 硬扣分**；申論少幾句 = 軟扣分。**先確保圖說完整**。
2. **除申論區外，圖面上任何一處文字不超過 3 行**——超過就代表該畫成圖。
3. **法規：圖上寫簡稱、申論引法規名稱、不背條號。**
