### 建議讀法

- **第一次接觸**：00 → 01 → 02（建立思維與基本盤）→ 03（掃過趨勢）→ 04/05（練答題模式）→ 06（看整卷長相）。
- **建立反射弧**：10 題眼庫 → 11 英雄條件庫 → 08 法規金句（看到題眼就反射出手法＋法源）。
- **考前衝刺**：14 衝刺計畫 → 00（反射弧）→ 10 主對照矩陣 → 12 命題預測（火力分配）→ 13 評分指南 → 06 總檢核表 → 09（確認沒記錯法規）。
- **寫模擬卷時**：開著 05 §1 的 SOP 與 06 的檢核表對照自評；寫完用 **07 失分標籤＋統計表**自我批改。

## 內容特色

- **核心精華先行**：五大思維模式、三大爭議、十個鑑別提問——先建立「思考反射弧」，再背題
- **Q&A 答題格式**：以考試問答方式編排，附標準定義與法源
- **歷屆真題教材**：97–114 年考題轉錄、考點解析、申論料庫與設計題模板
- **最佳答題模式**：考官評分順序、基地英雄條件導向、命名式場所營造、版面份量與「障眼法」戰術
- **法源逐條查證**：常見錯誤更正並標註出處（以全國法規資料庫為準）

## 適用對象

準備建築師、都市計畫技師、建管公務人員考試，或需系統性複習相關學科之考生。
