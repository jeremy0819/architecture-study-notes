## 內容特色

- **Q&A 答題格式**：以考試問答方式編排，附標準定義與法源
- **計算題解題步驟**：建蔽率、容積率、退縮、法定空地計算範例
- **圖面檢核**：六張必備圖面（S-01～S-06）標示要求與常見缺失
- **歷屆題型解析**：含都市計畫層級辨析、圖面判讀等陷阱題
- **歷屆真題教材**：敷地計畫與都市設計（80150）97–114 年考題轉錄、考點解析、申論料庫與設計題模板
- **都審原則與教學檢核**：都市設計審議八大原則 × 量化指標 × 四大圖說（計劃/平面/剖面/申論）扣分死角檢核；法源逐條查證更正並標註出處
- **申論版面模板**：五大主題版面骨架（文字/小圖/重標題框的相對位置），反射式作答、防空白與「障眼法」戰術

## 適用對象

準備建築師、都市計畫技師、建管公務人員考試，或需系統性複習敷地計劃學科之考生。
